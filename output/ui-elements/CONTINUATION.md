# UI 에셋 제작 인계

## 목표와 규칙

- 기준 문서: wiki/concepts/UI-Element-대체-기획서.md
- 사용자 요구: 생성 대상 에셋 전체를 런타임 적용 가능하게 만들고, 생성 즉시 Claude 적용 지시서도 갱신한다.
- 런타임 경로: assets/ui/<group>/<id>.webp 는 /ui/<group>/<id>.webp 로 참조한다.
- 원본 PNG: output/ui-elements/source/
- 권위 목록: assets/ui/manifest.json
- Claude 인계: output/ui-elements/CLAUDE-APPLY-THEME.md
- 각 에셋은 원본 PNG, WebP, 매니페스트 항목, Claude 적용 문구를 모두 갖춰야 한다.

## 완료

### 테마와 프레임

- 테마 4종: 벽 질감, 먹 가지, 외부 산수, 붓선 구분선
- P0 프레임: 한지 카드, 어두운 패널, 팝업, 제목 현판, 헤더 처마, 탭바, 요약 띠, 전투 무대, 초상, 행 쪽지
- P1 프레임: 비단 배너, 장비 슬롯과 6개 등급 프레임

### 버튼·탭·게이지

- P0 버튼 바탕 7종, 하단 탭 8종과 탭 아이콘 4종
- 게이지 프레임·채움·잔상·광택 P0 전부
- 문파 게이지 틀·채움

### 라벨과 아이콘

- P0 고정 라벨 30종, P1 고정 라벨 48종
- P0 아이콘 전부: 탭·기능·재화·능력치·전투 상태·행동 보조
- 글꼴과 OFL: output/ui-elements/fonts/

### 특수 패널

- 죽간 카드와 잠김 카드, 비단 선택기
- 무기고 배경, 기연 카드 뒷면, 사냥터 지도, 수련탑 입구, 오프라인 보상 밤 배경
- 단계 태그 3종

## 다음 제작 순서

1. scroll-parchment-dialog, frame-toast-note를 생성·등록한다.
2. 남은 P1 아이콘: 행동 보조, 장비 슬롯, 알림·보조 상태 아이콘을 스프라이트 묶음으로 생성·분리한다.
3. P1 간판 3종(sign-*)을 실제 글꼴 합성으로 만든다.
4. frame-gauge-sect와 기존 게이지의 inset 메타데이터를 매니페스트에 보강한다.
5. 기획서의 명시 ID를 매니페스트와 대조하고, 누락 ID를 제작한다.
6. 전체 매니페스트 JSON·파일 존재·알파·원본/표시 배율을 검수하고, Claude 인계 문서를 최종 적용 목록으로 정리한다.

## 검증

현재 매니페스트 검증은 JSON 파싱, 중복 ID, 누락 런타임 파일을 확인한다. 화면 적용 뒤에는 npm run lint와 npm run build도 실행한다.
