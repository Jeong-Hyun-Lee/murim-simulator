# style-board-v1

- 생성 도구: built-in image generation
- 생성 횟수: 1
- 프롬프트: 11.2 스타일 보드 지시를 바탕으로, 흰 회벽·먹색 기와·흑칠 목재·절제된 금박·남색 현판·청기와의 대비를 사용한 모바일 게임 UI 표본을 생성했다. 모든 판과 프레임 중심은 비워 두고 글자·숫자·한자·로고·워터마크를 금지했다.
- 검수: 지정한 버튼 네 종, 한지/강조 패널, 팝업 프레임, 죽간·비단 두루마리, 전투 액자, 닫기·뒤로·설정·전·영약 아이콘이 모두 있다. 글자와 워터마크는 없다. 팔괘 원판에 장식용 괘 획이 있으나 문자는 없다.
- 눈에 띄는 문제: 실제 개별 에셋으로 분리하기 전에는 모서리·반복 구간의 9-slice/3-slice 적합성을 판정할 수 없다.
