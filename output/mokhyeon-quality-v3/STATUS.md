# 목현 품질 재검토 — 미완료

2026-09-12. Ponytail을 적용하지 않고 캐릭터 이미지 생성 지침 및 내장 imagegen으로 시험 제작.

## 확인한 구현 문제

현재 `pack_all_from_spec.py`는 무기/머리카락/효과 포함 content bbox를 잘라 `px = center_x - w // 2`로 배치한다. 이는 몸통 기준 정렬이 아니므로 포즈에 따라 신체 중심이 이동한다. 모든 포즈의 최하단을 발 기준점에 맞추는 처리도 사망 포즈의 월드 기준점과 같다는 보장이 없다. 현재 목현 런타임은 520px 셀, anchor=(0.5,0.875)다.

영상 파일 존재는 확인했지만 로컬 영상 디코더가 없어 프레임을 직접 검토하지 못했다. 위 원인은 코드에서 확인한 사실이며 영상을 시청했다는 의미가 아니다.

## 시험 생성

- `idle-reference.png`: 외형 기준용 단일 대기 포즈. 실제 RGBA 확인. 패킹/축 정렬 미완료.
- `death-reference.png`: 단일 사망 마지막 포즈 후보. 외형/크기/무기 연속성 검수 및 패킹 미완료.
- 대기 6프레임 시트 및 단일 공격 포즈 후보는 체크무늬가 그려진 RGB로 출력돼 불합격. 기존 게임 파일에 적용하지 않음.

내장 생성 도구가 요청한 실제 투명도와 정밀 좌표를 일관되게 지키지 못했다. 알파 존재만으로 윤곽선 품질 합격을 선언하지 않는다. 기준 포즈 2장은 완성 모션 세트가 아니다. 기존의 회색 픽셀 삭제 스크립트나 전체 bbox 중앙 정렬을 재사용하지 않았다.

## 사용한 프롬프트 요지

기존 목현 대기 외형 참조. 페인터리 SD 비율/남색 긴 머리와 상투/흰 보라 도포/검정 금색 검집/검정 신발 고정. 오른쪽 응시. 단일 대기 기준 포즈, 4×2 대기 시트, 단일 우향 발도 공격 정점, 단일 우향 쓰러짐 마지막 자세 시험. 실제 투명 PNG, 정돈된 머리카락과 매끈한 윤곽선, 체크무늬/매트/그림자/문자 금지. 시트는 512px 셀과 (256,448) 기준점, 32px 여백 요청. 이 수치는 생성 요청이지 결과 보증이 아니다.
