# 흑시장 하수인 v1 제작 메모

- 외형 기준: 약 2.5등신 SD 체형, 거친 낮은 상투와 의심스러운 눈매, 숯빛 민소매 상인 호위 조끼, 탁한 청록색 교차깃 옷, 낡은 갈색 바지, 황동 엽전 장식, 돈주머니, 짧고 넓은 외날도를 사용한다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 제작 기준: `motion-master.png`에서 네 상태의 동일 인물·카메라·신체와 무기 비율을 먼저 고정하고, 각 4프레임 스트립은 직전 스트립을 함께 참조한다.
- 공통 불변값: 실제 투명 RGBA, 같은 인물·2.5등신·머리 크기·신체 배율·카메라, 적의 왼쪽 응시, 오른쪽 루트, 같은 바닥선, 전신·무기·궤적 안전 여백, 모션별 확대·재중앙화·좌우 반전 금지.
- 패킹: 네 모션 공통 896px 셀, 공통 배율 `0.93`, 오른쪽 루트 `(612, 770)`, 공통 지면 y=770을 사용한다.
- 상태: 4모션 54프레임 생성·패킹·런타임 연결 완료. 대2의 `grunt`에 표시 배율 `0.45`, 두 공격 접촉 인덱스 7로 적용했다.
