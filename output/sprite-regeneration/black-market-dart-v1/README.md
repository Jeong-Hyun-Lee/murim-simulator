# 흑시장 독침꾼 v1 제작 메모

- 외형 기준: 약 2.5등신 SD 체형, 낮은 상투와 청흑색 복면, 숯빛 후드 망토, 탁한 청록색 교차깃 옷, 황동 엽전 장식, 독병, 독침과 짧은 취관을 사용한다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 제작 기준: `motion-master.png`에서 네 상태의 동일 인물·카메라·신체·도구 비율을 먼저 고정하고, 각 4프레임 스트립은 직전 스트립을 함께 참조했다.
- 공통 불변값: 실제 투명 RGBA, 같은 인물·2.5등신·머리 크기·신체 배율·카메라, 적의 왼쪽 응시, 오른쪽 루트, 같은 바닥선, 전신·도구·독 효과 안전 여백, 모션별 확대·재중앙화·좌우 반전 금지.
- 공격 구분: attack1은 손으로 독침을 던지고, attack2는 짧은 취관으로 독침을 발사한다. 두 공격 모두 8번째 프레임이 접촉 프레임이다.
- 패킹: 네 모션 공통 896px 셀, 공통 배율 `0.93`, 오른쪽 루트 `(596, 770)`, 공통 지면 y=770을 사용한다. 쓰러짐의 오른쪽 안전 여백까지 동일 셀에 수용하도록 전 모션에 같은 루트를 적용한다.
- 상태: 4모션 54프레임 생성·패킹·런타임 연결 완료. 대2의 `archer`에 표시 배율 `0.45`, 두 공격 접촉 인덱스 7로 적용했다. localhost 2-7의 375px·430px 화면에서 방향·체급·바닥선·잘림 없음과 콘솔 오류 0건을 확인했다.
