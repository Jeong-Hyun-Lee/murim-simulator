# 팽가 무사 v1 제작 메모

- 외형 기준: 약 2.5등신 SD 체형, 단정한 상투와 청회색 끈, 아이보리 교차깃 속옷, 남색 구름무늬 무복, 적갈색 가문 허리띠와 원형 문장, 강철 완갑, 두꺼운 환두 박도를 사용한다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 제작 기준: 내장 이미지 생성으로 `motion-master.png`에서 네 상태의 동일 인물·카메라·신체·무기 비율을 먼저 고정하고, 각 4프레임 스트립은 직전 스트립과 마스터를 함께 참조했다.
- 공통 불변값: 실제 투명 RGBA, 같은 인물·2.5등신·머리 크기·신체 배율·카메라, 적의 왼쪽 응시, 오른쪽 루트, 같은 바닥선, 전신·박도·타격 효과 안전 여백, 모션별 확대·재중앙화·좌우 반전 금지.
- 공격 구분: attack1은 허리 높이 수평 베기, attack2는 머리 위에서 왼쪽 아래로 내리치는 패도식 내려베기다. 두 공격 모두 8번째 프레임이 접촉 프레임이다.
- 패킹: 네 모션 공통 896px 셀, 공통 배율 `0.93`, 오른쪽 루트 `(568, 770)`, 공통 지면 y=770을 사용한다. 쓰러짐의 오른쪽 안전 여백을 개별 축소 없이 수용하도록 전 모션에 같은 루트를 적용하며 32px 안전 여백을 자동 검사한다.
- 상태: 4모션 54프레임 생성·패킹·런타임 연결 완료. 대3의 `grunt`에 표시 배율 `0.45`, 두 공격 접촉 인덱스 7로 적용했다. localhost 3-1~3-2의 375px·430px 화면에서 방향·체급·바닥선·쓰러짐·잘림 없음과 콘솔 오류 0건을 확인했다.
