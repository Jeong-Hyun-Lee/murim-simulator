# 사공 추종자 v1

- 방향: 화면 오른쪽 배치, 화면 왼쪽 응시, 좌우 반전 없음
- 모션: `idle` 12, `attack1` 16, `attack2` 16, `death` 10
- 공통 규격: 896×896px 셀, 제작 배율 `0.93`, 루트 `(612,770)`, anchor `(0.6830357,0.859375)`
- 공격1: 낮은 수평 베기, 공격2: 머리 위에서 왼쪽 아래로 내려베기
- 접속 기준: `idle` 1번 원본을 두 공격의 첫·마지막 프레임에 픽셀 단위로 재사용
- 예외: `idle` 마지막은 별도 사이 프레임, `death` 첫 프레임은 같은 배율·루트의 피격 반동 자세
- 공격 접촉: 두 공격 모두 9번째 프레임(런타임 인덱스 8)
- 예상 런타임 표시 배율: `0.45`
- 결과: 단일 PixiJS PNG/JSON 패킹과 알파·여백·기준점·duration·경계 해시 검증 완료, 대4 `grunt` 런타임 적용 완료

검증 수치와 소스 해시는 `verification.json`, 정상/저속 재생은 모션별 GIF, 전체 정렬은 `forbidden-art-follower-v1-cells.png`에서 확인한다.
