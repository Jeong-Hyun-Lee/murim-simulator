# 신규 투명 모션 시트 구현 참고 명세

## 적용 범위와 상태

대상: `transparent/`의 주인공·혈랑채 보스·졸병·궁수·정예산적 모션 시트 27장.

**배경 제거만 완료된 원본 크기의 이미지다. 동일한 프레임 간격·신체 크기로 패킹된 런타임 시트가 아니다.** 이전 배경 제거 작업에서는 픽셀을 이동하거나 크기를 변경하지 않았다. 이번 문서는 측정 및 구현 참고용이며 게임 이미지나 재생 코드를 변경하지 않는다.

## 프레임별 크기와 여백 데이터

`layout-measurements.json`에 27장 각각의 명목 프레임 측정값을 기록했다.

- `nominalRect`: 시트 내 명목 셀의 x/y/w/h.
- `alphaBoundsWithinNominalCell`: 해당 셀 안 알파 영역의 [left, top, right, bottom]. 셀 기준 좌표이며 오른쪽/아래는 미포함.
- `contentSizeWithinNominalCell`: 해당 영역의 너비/높이. **무기·궤적을 포함하며 신체 크기가 아니다.**
- `transparentMarginsWithinNominalCell`: 좌/상/우/하 투명 여백.
- `opaquePixelsOnCellEdge`: 명목 셀 가장자리의 알파 양수 픽셀 수(모서리 중복 집계).
- `safeForUniformSlicing: false`: 아직 게임용 균등 분할을 승인하지 않은 상태.

인접 셀의 오른쪽/왼쪽 여백 합은 명목 격자 내 수평 투명 띠를 참고할 때만 쓴다. 프레임 소유권이 확정되지 않은 상태이므로 실제 포즈 사이의 정확한 거리로 간주하지 않는다. 이 JSON을 런타임 프레임 메타데이터 대신 로드하면 안 된다.

## 최종 패킹 목표 — 역할별 중심축

제작 기준은 [캐릭터 이미지 생성 지침](../../wiki/concepts/캐릭터-이미지-생성-지침.md)을 따른다. 아래는 신규 제작 목표이며 위의 기존 PNG 실측값을 바꾸지 않는다.

| 항목 | 목표 |
| --- | --- |
| 공통 프레임 W×H | 6모션 전체의 최대 공격 범위·무기·궤적·머리카락·쓰러짐을 포함한 영역 + 안전 여백 |
| 기본 셀 / 시트 | 512×512px / 4열×2행 2048×1024px, 부족하면 제작 세트 전체를 같은 규격으로 확대 |
| 안전 여백 | 네 변 최소 32px, 인접 콘텐츠 최소 분리 64px |
| 주인공 루트 | 프레임 왼쪽, 기본 (W×0.25,H×0.875); 오른쪽에 공격 공간 확보 |
| 적 루트 | 프레임 오른쪽, 기본 (W×0.75,H×0.875); 왼쪽에 공격 공간 확보 |
| 신체 배율 | 캐릭터별 기준 포즈의 머리·몸통 비율을 모든 모션에서 유지 |
| 빈 공간 | 대기·피격·승리도 공격과 같은 여백 유지, 트리밍·개별 자동 줌 금지 |

25%/75%는 기본 목표다. 전방 공격과 후방 검집·머리카락이 모두 들어오는지 실측해 생성 전에 최종 기준점을 확정한다. 주인공은 왼쪽, 적은 오른쪽이라는 방향 규칙은 유지한다. 확정 후 모든 모션에서 루트 좌표를 고정한다.

정렬 기준은 캐릭터 루트이며 무기·궤적을 포함한 바운딩 박스 중앙이 아니다. 사망에서도 최하단 픽셀을 발바닥으로 간주해 재정렬하지 않는다. 자세 변화는 고정 루트에 상대적으로 표현한다. 같은 제작 세트의 모든 모션/프레임은 같은 W×H이며 특정 공격 프레임만 축소하거나 셀을 늘리지 않는다.

최종 패킹 검수를 통과한 시트에서만 다음 공식을 사용한다:

```text
x = (i % 4) * W
y = floor(i / 4) * H
w = W
h = H
playerAnchor = (0.25, 0.875)  // 기본값, 실제 확정 rootX/W와 rootY/H 사용
enemyAnchor  = (0.75, 0.875)
```

JSON에 최종 역할별 root/anchor와 프레임 좌표·재생 시간을 기록하고 실제 로더가 이를 적용하는지 확인한다. anchor만 바꾸고 그림의 배치를 그대로 두면 안 된다. 대기→공격→회복→대기, 피격 복귀, 사망/승리 진입을 같은 월드 좌표에서 재생해 중심축·신체 크기·손/무기 위치의 튐과 잘림을 검수한다. 사망은 마지막 자세를 홀드한다. 재생 시간은 기존 게임 타이밍 또는 별도 확정값을 따른다.

이번 규칙 명시는 이미지 재패킹이나 런타임 코드 변경이 아니다.
