## built-in imagegen 프롬프트 세트

- 공통: 승인 외형과 2.5등신 비율을 잠그고, 화면 왼쪽 응시·좌우 반전 금지·실제 투명 RGBA·동일 카메라 거리·공통 발/골반 루트·셀 사이 완전 투명 간격을 반복 명시했다.
- idle: 4프레임 스트립 3개. 공격1 준비 자세의 머리·얼굴·어깨·몸통 크기를 기준으로 호흡과 눈·천의 미세 변화만 생성했다.
- attack1: 4프레임 스트립 4개. 준비→화살 꺼내기→장전→만작→왼쪽 발사→활 반동→대기 복귀 순서다.
- attack2: 4프레임 스트립 4개. 낮은 자세→깊은 만작→금색 속도 궤적의 강사→큰 반동→대기 복귀 순서다.
- death: 4+4+2프레임 스트립. 피격→무릎/손 접지→한 방향으로 옆으로 붕괴→착지→홀드 순서이며 마지막 두 셀만 사용한다.
- 교정: 공격 복귀 구간의 중복 활 잔상을 제거하고, death 중간의 다시 일어서는 역행을 재생성했다. 대기 원본 높이 622~~640px가 공격 시작 536px보다 컸던 1차 결과는 사용하지 않고 544~~553px로 다시 생성했다.
