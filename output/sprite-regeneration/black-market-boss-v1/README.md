# 흑시장 조직 두목 v1 제작 메모

- 외형 기준: 약 2.5등신 SD 체형, 은빛 앞머리가 섞인 흑발 상투와 짧은 수염, 청흑색 상인 겹옷, 황동 엽전 장식, 장부 주머니, 엽전 손잡이 지팡이검으로 설계했다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 패킹: 네 모션 공통 896px 셀, 공통 배율 `0.93`, 오른쪽 루트 `(620, 770)`, 공통 지면 y=770을 사용한다.
- 상태: 4모션 54프레임 생성·패킹·런타임 연결 완료. 2-10의 375px·430px 화면에서 방향·체급·바닥선과 브라우저 오류 0건을 확인했다.

## built-in imagegen 프롬프트 세트

- 공통 마스터: 혈랑채 두목·정예산적의 SD 화풍과 대2 흑시장 배경의 청색 야간·금색 등불 팔레트만 참고했다. 외형·무기·색은 새로 만들고, 대기·공격1 접촉·공격2 접촉·최종 쓰러짐을 한 보드에서 먼저 고정했다.
- 공통 불변값: 실제 투명 RGBA, 정확히 같은 인물·2.5등신·머리 크기·신체 배율·카메라, 적의 왼쪽 응시, 오른쪽 루트, 같은 바닥선, 전신·무기·궤적 32px 안전 여백, 모션별 확대·재중앙화·좌우 반전 금지.
- idle: 4프레임 스트립 3개. 발과 루트를 고정하고 호흡, 머리카락, 술, 옷자락만 미세하게 움직여 12번에서 1번 자세로 닫힌다.
- attack1: 4프레임 스트립 4개. 대기→발도·머리 위 축력→왼쪽 아래 대각 베기(8번 접촉)→같은 방향 관성 감쇠→납도·대기 복귀다.
- attack2: 4프레임 스트립 4개. 대기→낮은 축력→왼쪽 직선 찌르기(8번 접촉)→직선 회수→납도·대기 복귀다. 공격1과 구분되도록 넓은 초승달 궤적을 금지했다.
- death: 4+4+2프레임. 대기→충격→한쪽 무릎→양손 지지→왼쪽 측면 붕괴→같은 바닥선의 최종 홀드다. 마지막 소스의 3·4번 셀은 완전 투명하다.
- 연속 생성: 모든 스트립은 마스터 보드와 직전 스트립을 함께 참조해 경계 자세가 역행하지 않도록 했다.
