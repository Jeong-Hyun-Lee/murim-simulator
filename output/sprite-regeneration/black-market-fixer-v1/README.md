# 흑시장 해결사 v1 제작 메모

- 외형 기준: 약 2.5등신 SD 체형, 눈썹 흉터와 굵은 상투, 청흑색 중장 상인 호위복, 적갈색 허리띠, 황동 견갑·완갑·엽전 장식, 쇠테를 두른 흑목 곤봉을 사용한다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 제작 기준: 내장 이미지 생성으로 `motion-master.png`에서 네 상태의 동일 인물·카메라·신체·무기 비율을 먼저 고정하고, 각 4프레임 스트립은 직전 스트립과 마스터를 함께 참조했다.
- 공통 불변값: 실제 투명 RGBA, 같은 인물·2.5등신·머리 크기·신체 배율·카메라, 적의 왼쪽 응시, 오른쪽 루트, 같은 바닥선, 전신·곤봉·타격 효과 안전 여백, 모션별 확대·재중앙화·좌우 반전 금지.
- 공격 구분: attack1은 허리 높이 수평 곤봉타, attack2는 머리 위에서 내려찍는 지면 강타다. 두 공격 모두 8번째 프레임이 접촉 프레임이다.
- 패킹: 네 모션 공통 896px 셀, 공통 배율 `0.93`, 오른쪽 루트 `(596, 770)`, 공통 지면 y=770을 사용한다. 모든 모션을 같은 셀과 배율로 유지하며 32px 안전 여백을 자동 검사한다.
- 상태: 4모션 54프레임 생성·패킹 완료. 런타임에서는 대2의 `elite`에 표시 배율 `0.45`, 두 공격 접촉 인덱스 7로 적용한다.
