# 혈랑채 정예산적 v3 제작 메모

- 외형 기준: 기존 정예산적의 검은 머리·수염·붉은 머리띠·갈색 방어구·대도 디자인을 유지하고, 체형은 약 2.5등신 SD로 새로 설계했다.
- 방향: 화면 오른쪽 배치, 왼쪽 응시. 좌우 반전 금지.
- 모션: idle 12 / attack1 16 / attack2 16 / death 10.
- 패킹: 네 모션 공통 896px 셀·단일 신체 배율·오른쪽 루트·공통 지면을 사용한다.

## built-in imagegen 프롬프트 세트

- 공통: 4상태 마스터에서 외형·2.5등신 비율·대도 크기·카메라 거리를 먼저 고정하고, 모든 제작 스트립에 같은 마스터를 참조했다.
- idle: 4프레임 스트립 3개. 발·골반·대도 위치를 잠그고 호흡·눈·머리띠 꼬리만 미세하게 변화시켰다.
- attack1: 4프레임 스트립 4개. 대기→머리 위 예비동작→왼쪽 수평 베기→반동→대기 복귀 순서이며, 초기 경계 역행 초안은 사용하지 않고 이전 스트립의 마지막 프레임을 참조해 연속 재생성했다.
- attack2: 4프레임 스트립 4개. 대기→머리 위 축력→왼쪽 아래 내려베기→낮은 반동→대기 복귀 순서다.
- death: 4+4+2프레임 스트립. 피격→무릎/손 접지→한 방향으로 옆으로 붕괴→바닥 최종 홀드 순서다.
- 공통 금지: 모션별 확대·축소, 프레임 재중앙화, 발 미끄러짐, 방향 반전, 불투명 배경, 잘린 칼·궤적을 허용하지 않는다.
