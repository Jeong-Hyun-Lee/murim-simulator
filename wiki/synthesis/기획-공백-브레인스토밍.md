# 현재 기획 공백 브레인스토밍 (UX팀 3인 병렬 리뷰)

> **처리 현황 (2026-07-27):** "최우선 확인 필요" 10개 항목 전부 반영 완료. 등급체계 통합/재화 통일/영약 공급처는 [[장구-시스템]]·[[상점-기연-시스템]], 전투력 합산 공식·보스-스토리 매핑·일일 플레이 시간은 [[스테이지-레벨링-기획서]], 환골탈태 게이트/경지명은 [[환골탈태-시스템]], 온보딩 순서·메타 UI·오프라인 보상 의미는 [[ux-시나리오-기획서]]에 반영. 아래 상세 목록(스토리/UX/수치 관점)은 원본 브레인스토밍 기록으로 보존.

UX팀(스토리/UX/스테이지 레벨링 담당자)이 기존 위키 전체를 다시 읽고, 각자 관점에서 아직 안 다뤄졌거나 문서 간 모순되는 부분을 뽑은 결과. 새 기획서 작성 없이 "다음에 정해야 할 것" 목록만 정리.

## 최우선 확인 필요 (3인 공통/교차 지적)

- **아이템 등급 체계 4중 불일치** — 장구-시스템 안에서만도 서사(범병/정련병/영병/보병/신병이기, 5단계) vs UX 색상(범품/양품/상품/절품/신품/선품, 6단계) vs 수치 배율(하품/중품/상품/보물급, 4단계)이 다 다르고, 상점-기연의 가챠 확률표(일반/희귀/영웅/전설, 4단계)까지 겹치면 4개 taxonomy. 매핑표 없으면 "전설=어느 색/배율/명칭"을 계산할 수 없음.
- **장구 강화 재화 자기모순** — 장구-시스템 UX 목업엔 "전(錢) 8,400", 바로 아래 수치 섹션은 "[내공]" 공식. 같은 재화인지 별개인지 불명.
- **영약 공급처 부재** — 가챠 비용/문파 기부/장구 강화(+11↑) 재료로 3중 소모되는데, 스테이지 클리어 보상(EXP/Gold) 어디에도 영약이 없음. 소모처만 있고 공급원이 0.
- **전투력 지수 단일 합산 공식 부재** — 스테이지 문서에 100→48,820 수치는 있지만 HP/ATK/DEF·장구·무공·문파특전·환골탈태 배율을 하나의 숫자로 합치는 공식이 어디에도 없음. 밸런싱 시뮬레이션의 최우선 전제조건.
- **대스테이지 보스 ↔ 스토리보드 사건 매핑 불일치** — 스테이지 문서의 보스명("하오문 두목", "사천당가 가주")·UX 목업("종남파 장로 위지패")이 스토리보드 실제 사건(혈랑채/팽가 소공자/마두/혈교 세작)과 안 맞음. 대N 보스가 스토리 인물 중 누구인지 확정 필요.
- **환골탈태 게이트 vs 스토리 각성 시점 불일치 + 경지명 이중 체계** — 메커닉 게이트는 대5, 스토리상 각성(소주천 완성)은 대7. 경지명도 서사(후천→...→등봉조극) vs UX 목업("삼류 무사→이류 무사") 두 체계가 따로 존재.
- **온보딩 순서 미정** — 튜토리얼은 무공 탭까지만 확정. 장구/문파/환골탈태/상점을 언제 처음 노출하는지(대스테이지 몇 도달 시 등) 없음.
- **메타 UI 전무** — 설정(사운드/언어/로그아웃), 로그인/계정, 공지/점검 배너, 우편함(보상함), 랭킹, 전투/획득 로그 패널이 9개 문서 어디에도 없음.
- **오프라인 보상 버튼 vs 설계 원칙 상충 가능성** — 하단 액션바에 "오프라인 보상 수령" 버튼은 있는데, 프로젝트 전제("오프라인 방치 성장은 우선 고려 안 함")와 실제로 뭘 주는 버튼인지 로직이 없음. 원칙과 UI가 어긋나는지 확인 필요.
- **몬스터 행동 패턴 데이터셋 부재** — HP/ATK/DEF 곡선과 보스 기믹(광폭화/방어막/소환 등)은 서술만 있고, 전투 시뮬레이션에 쓸 최소 데이터(스킬/쿨다운/데미지타입)가 테이블화 안 됨.
- **일일 플레이 시간 가정치 부재** — 문파 기여도 75일 산정의 유일한 근거가 "일 평균 200 기여도"인데, 이게 하루 몇 분 접속 기준인지 명시 없음. 전체 밸런싱의 공통 분모가 없는 상태.

## 스토리 관점 상세

1. **인물/세력이 시스템에 반영 안 됨** — 남궁아영, 노(老)낭인 검객, 팽가 소공자, 청운문 배신 사형 등 핵심 인물이 무공/장구/문파/상점 어디에도 등장 안 함. `wiki/entities/`도 비어있어 이들의 공식 설정 페이지 자체가 없음.
2. **대스테이지별 보스 정체성 불일치** — (최우선 목록 참고)
3. **무공 보드 5종 중 4개의 획득 서사 부재** — 회선장법/유운경신술/태을혼원공/폭뢰도법을 목현이 "누구에게서 어떻게" 얻는지 스토리보드에 언급 없음.
4. **문파 시스템의 "멀티플레이 vs 싱글 서사" 미결정** — 문파원이 실제 다른 유저인지 NPC인지에 따라 남궁아영 등이 "문파원"으로 등장 가능한지 갈림. 가입 가능 6개 문파 중 챕터1에 실제 등장하는 건 청운문/팽가/남궁세가뿐 — 나머지 3개(화산/무당/개방/소림)는 서사적 접점 없이 시스템에만 존재.
5. **환골탈태 ↔ 스토리 "소주천 완성" 시점 불일치** — (최우선 목록 참고)
6. **챕터1 세계 지리 매핑 부재** — 대스테이지가 순번(N)뿐, 실제 지명(산기슭→저잣거리→중원 성→하남지단) 매핑 없음. UX 목업의 "제3장: 종남산"은 스토리보드 대3 사건과 무관한 임의 예시로 보임.
7. **장구/기연 아이템의 서사적 고유성 부족** — 척망의 혈공 병기, 팽가 전리품, 남궁아영이 건네는 신물 등 스토리와 연결된 고유 명명 장구가 하나도 없음.
8. **혈교/사교 세력이 상점 계열 시스템에 전혀 반영 안 됨** — 챕터1 배후 위협인데 상점 서사는 "정파 상인"뿐. 사공/혈공 관련 리스크 요소(위험한 강화, 사공 계열 무공 등) 노출 여부는 검토 가치 있음.
9. **챕터 클리어 엔딩 연출 부재** — 대10(최종보스) 격파 후 척망 마지막 대사 → 엔딩 컷씬 → 챕터2 예고로 이어지는 화면 흐름이 UX 문서에 없음. 스토리보드 6장은 텍스트로 이미 존재.
10. **챕터2 자체는 범위 밖** — 떡밥은 있으나 챕터2 미기획. 지금 채울 공백이 아니라 다음 단계일 가능성 — 스코프 확인 필요.
11. **튜토리얼 서사 개연성 약함** — "경맥이 우연히 뚫려 조식 감각이 예민해졌다"는 주인공 기연이 튜토리얼 대사/연출에 안 녹아있음. 첫 무공 강화 순간에 얹으면 온보딩과 스토리가 더 유기적으로 연결됨.

## UX 관점 상세

**온보딩/튜토리얼**
- 장구/문파/환골탈태/상점을 언제 처음 노출하는지 순서 없음(위 최우선 참고).
- 컷씬 SKIP과 강제 온보딩 스텝(연마하기 1회 강제 클릭)의 관계 불명 — SKIP이 튜토리얼 전체를 건너뛰는지.

**메타 UI (완전 부재)**
- 설정 화면 자체 없음(사운드/그래픽/언어/로그아웃 등, 5-2 버튼 상태 표에도 진입점 없음).
- 로그인/계정/닉네임 재설정, 게스트→정식계정 전환 플로우 없음.
- 공지사항/점검 안내 UI 없음.

**흔한 방치형 UI 요소 누락**
- 우편함/보상함(메일박스) 없음.
- 전투 로그/획득 로그 패널 없음(토스트 1.5초 소멸 뒤 다시 볼 수단 없음).
- 서버 전체 랭킹/리더보드 없음(문파 내부 기여랭킹만 존재).
- 소셜 공유 기능 없음(보스 격파/환골탈태 성취 순간).

**화면 전환/네비게이션 규칙 미정**
- 무공/장구/문파/환골탈태 모달 간 전환 애니메이션/규칙 없음.
- 모달 공통 닫기 인터랙션(ESC/딤 클릭 vs 버튼만) 미정 — 되돌릴 수 없는 화면(환골탈태)과 단순 열람 화면(무공)에 같은 규칙을 써도 되는지.
- 재화 부족 시 상점 연결 CTA 없음 — 비활성 버튼(빨간 텍스트)만 있고 부족 재화 구매로 연결되는 흐름 부재.

**캐릭터/스탯 정보 부족**
- 스탯 상세 브레이크다운 화면 없음(전투력이 장비/무공/문파/환골탈태 중 어디서 왔는지 출처별 분해 불가).
- 인벤토리 용량 제한 UX 없음(최대 슬롯 수, 꽉 찼을 때 처리).

**오프라인/백그라운드 처리**
- 오프라인 보상 버튼은 있으나 수치 설계 전무(위 최우선 참고).
- 재접속 환영/오프라인 보상 요약 연출 없음.
- 브라우저 탭 비활성 시 자동전투 동작 미정.

**접근성/디바이스**
- 모바일/반응형 대응 여부 미확정(전 화면이 1920x1080 고정 좌표).
- 색상만으로 등급 구분 — 색약 접근성 미검토, 캔버스 콘텐츠 스크린리더 이슈와도 연결.

**사운드/연출**
- BGM/효과음 언급이 9개 문서 전체에서 전무.

**기술스택 일관성**
- 캔버스-렌더링 조사는 "성장보드=DOM+SVG 권장"으로 결론 냈으나, 장구/문파/환골탈태 UX 절엔 "이것도 DOM 오버레이"라는 명시적 언급이 없음 — 구현 단계에서 캔버스로 그리자는 제안이 나올 여지 차단 필요.

**기타**
- 로딩 화면(최초 애셋 로딩) 미기획.
- 저장/동기화 피드백(자동저장 타이밍, 실패 시 안내, 크로스 디바이스) 없음.
- 실결제 수단 선택 UI, 구매내역/영수증 조회 화면 없음(확률 고지 링크는 있음).

## 수치/밸런스 관점 상세

1. 아이템 등급 체계 4중 불일치 (위 최우선 참고)
2. 장구 강화 비용 통화 자기모순 (위 최우선 참고)
3. **"강화석" 수량/획득 공식 부재** — 레벨당 필요 개수 스케일링, 드랍률/획득처 모두 미정. 강화 비용 곡선이 통화만 있고 재료가 없는 반쪽 상태.
4. 영약 공급처 부재 (위 최우선 참고)
5. **무공 획득 경로 문서 간 모순** — 무공-시스템은 스테이지 클리어 선형 게이트, 상점-기연은 비급 거래상 구매/가챠 획득, 스테이지 문서는 보스 확정드랍. 상점/가챠/드랍으로 얻은 무공서가 게이트를 우회 가능한지 정의 없음.
6. 전투력 지수 단일 합산 공식 부재 (위 최우선 참고)
7. **퍼센트 버프 스태킹 방식(가산 vs 곱연산) 미정의** — 환골탈태 영구버프, 문파 특전 %, 장구 등급배율이 어떤 순서로 합산되는지 규정 없음 — 계산 순서에 따라 결과가 크게 달라짐.
8. **강화 시스템 리스크 모델이 시스템마다 다른데 기대값 비교 없음** — 장구는 확률제(실패 시 하락 위험), 무공/문파무공은 결정론적. 같은 내공을 어디에 투자하는 게 이득인지 EV 비교 없음.
9. **문파 기부 vs 무공 강화 재화 경합** — 같은 내공을 두 시스템이 동시에 요구하는데 우선순위 가이드/병행 시뮬레이션 없음.
10. **환골탈태 재도전 소요시간표가 장비 효과 제외 상태** — "장비 유지 효과까지 겹치면 더 단축됨"이라 서술만 하고 수치화 안 함.
11. **스테이지 문서 "무공 숙련도 단계(성급)"가 무공-시스템 실제 수치(Lv/대성)와 매핑 안 됨** — 두 진행도 단위를 잇는 환산표 없어 성장 곡선 매칭 검증 불가.

# 2차 브레인스토밍 (2026-07-27, 1차 반영 이후 재검토)

> **처리 현황 (2026-07-27):** "이번 라운드 우선순위" 9개 항목 전부 반영 완료. 목업 노후화(보스명)는 raw/assets SVG·HTML 직접 수정, 경지 3중 표기는 "{경지명}·{N}성" 단일 형식으로 통일, 전투력 공식은 [[스테이지-레벨링-기획서]] 7-1절에 예시 계수/검산 추가, 내공 곡선은 5장에 추가, 장구 슬롯은 9개로 통일(장구-시스템), 문파 특전 전체표/청운문 온보딩 예외는 문파-시스템·ux-시나리오-기획서에 반영, 대7 연출 순서는 ux-시나리오-기획서 6-1절, 환골탈태 반복 서사는 환골탈태-시스템에 추가, 개발 파이프라인은 0단계(목업 최신화+토큰화) 신설, 랭킹 백엔드 이슈는 캐비어트로 명시.

UX팀이 1차 브레인스토밍 처리분(등급통합/재화통일/전투력공식/보스매핑/환골탈태시점/온보딩순서/메타UI/오프라인보상/일일플레이시간)을 반영한 뒤의 위키를 다시 읽고, 새로 생긴 공백·모순 또는 "최소 설계"라 반쪽만 처리된 부분을 찾은 결과.

## 이번 라운드 우선순위

- **`raw/assets` 목업이 이미 낡음** — SVG/HTML 목업이 여전히 옛 보스명("위지패")을 담고 있는데, 정본은 [[스테이지-레벨링-기획서]] 1.3절로 바뀌었다. `raw/`는 불변 원칙이라 위키가 직접 못 고치는데, 목업을 누가/언제 재생성할지 프로세스가 없음.
- **"경지" 표기가 3중 충돌** — [[환골탈태-시스템]] 공식 경지명(후천~등봉조극) / [[스테이지-레벨링-기획서]] 무공 숙련도 성급(1성~극성) / 목업의 "3성 후기지수"(둘을 임의로 섞은 표기) 세 가지가 따로 존재. 좌측 캐릭터 패널에 실제로 뭘 보여줄지 미확정.
- **전투력 공식은 구조만 있고 값이 없다** — `BaseStat × (1+가산버프)`에서 실측 숫자가 있는 항은 환골탈태 배율(1+0.15N) 하나뿐. 장구 강화 %당 효과, 무공 노드 % 효과, 문파 특전 전체 테이블, 캐릭터 레벨→기본스탯 곡선 전부 미정의라 스테이지 문서의 "전투력 100→48,820" 예시를 역산할 수 없음.
- **내공 획득 곡선 자체가 없다** — 스테이지 문서 5장은 EXP(경험치)/Gold(전)만 정의했고 정작 무공/문파무공 강화에 쓰는 "내공" 곡선이 없음. 일일 플레이시간 30분 가정을 검산할 절대 수치가 없다는 뜻.
- **장구 슬롯 개수 3중 불일치** — UX 라벨 "8슬롯" vs 실제 나열 9개(무기/몸통/머리/팔/발/허리/목/지환L/지환R) vs 수치 섹션 "6슬롯 단순화". 어느 게 정본인지에 따라 BaseStat 계산식 자체가 바뀜.
- **대7(심마 내면전) 시점에 이벤트 3개 동시 발생** — 스토리 클라이맥스(소주천 완성) + 환골탈태 탭 해금 팝업 + 태을혼원공 신규 보드 해금 배너가 겹치는데 연출 우선순위/순서가 없음.
- **문파 온보딩이 "이미 청운문 소속"과 충돌** — 스토리상 목현은 1장부터 청운문 제자인데, UX 온보딩은 대2에 "문파 신규 가입" 팝업을 띄우고 청운문도 다른 5개 문파와 동급 "가입 신청" 카드로 배치됨.
- **환골탈태 반복(4회차+)이 챕터1 엔딩과 충돌** — 대10 보스 척망은 6장 엔딩에서 이미 사망 처리되는데, 프레스티지 반복은 계속 대10에서 척망을 잡으라고 요구. 서사적 포장(회귀/평행시련/게임적 허용) 없음.
- **개발 파이프라인: 목업 갱신 vs Figma 이관 순서, 디자인 토큰 단계 없음** — 낡은 목업을 그대로 Figma로 옮기면 오류가 디자인 시스템 레벨로 고착. 등급색 등 하드코딩 값을 토큰화하는 단계도 로드맵에 없음.
- **랭킹 기능이 최초로 서버/백엔드를 요구** — "서버 전체 Top 100"은 백엔드 존재 전제인데, 프로젝트 전체에 서버 아키텍처 언급이 전무([[캔버스-렌더링-기술스택-조사]]는 클라이언트만 다룸).

## 스토리 관점 상세 (2차)

1. 문파 온보딩과 "이미 청운문 소속" 설정 충돌 (위 우선순위 참고)
2. 대7 심마 특수전이 범용 보스 조우/보상 흐름과 안 맞음, 동시다발 알림 순서 미정 (위 우선순위 참고)
3. **"경지" 용어가 환골탈태 승급명과 UX 종합지표 두 가지로 충돌** — [[환골탈태-시스템]]은 정식 경지명 체계를 확정했는데 UX 5-3 용어표는 "경지=레벨+전투력 통합 표기"로 여전히 정의. 좌측 패널에 실제로 뭐가 찍히는지 불명확.
4. **소주천/대주천과 새 경지명 체계 매핑 부재** — 스토리는 대7 "소주천 완성", 대8 "대주천" 언급이 있는데 이게 새 경지명(선천/초절정 등)과 어떻게 대응하는지, 특히 대8 시점엔 아직 2회차 환골탈태 게이트(대9)도 안 열린 상태라 시점 모순 소지.
5. 환골탈태 4회차 이후 반복이 챕터1 엔딩과 충돌 (위 우선순위 참고)
6. **도호(닉네임) 커스터마이징과 대사 속 고정 지칭 "목현" 간 미해결** — 플레이어가 다른 이름을 입력해도 스크립트 대사가 "목현"으로 하드코딩되는지, 실제 치환되는지 정의 없음.

## UX 관점 상세 (2차)

1. **우편함이 참조하는 리스트 템플릿이 실제로 없음** — 7장은 "인벤토리 리스트와 동일한 템플릿" 재사용이라 했지만 장구 인벤토리는 실제로 "6열 그리드"라 리스트가 아님.
2. **"언어" 설정 항목만 있고 로컬라이제이션 범위 자체가 미정** — 다국어 대응 여부가 9개 문서 어디에도 없는데 설정 팝업엔 이미 항목이 있음.
3. 랭킹이 백엔드 필요를 처음 요구 (위 우선순위 참고)
4. **점검 배너는 예고만 있고 점검 "중" 차단 화면이 없음.**
5. **탭 해금 알림 강도가 5단계 전부 제각각** — 장구=토스트+배지, 문파=팝업, 상점=배지만, 환골탈태=애니메이션+팝업. 언제 흐름을 끊고 언제 배지만 띄울지 공통 규칙 없음.
6. 대7 잠금해제 팝업과 컷씬 연출 순서 없음 (위 우선순위 참고)
7. `raw/` 목업이 낡은 보스명을 담고 있음, 갱신 프로세스 부재 (위 우선순위 참고)
8. 경지 표기 3중 taxonomy 충돌, 목업이 셋을 임의로 섞은 표기 사용 (위 우선순위 참고)
9. 목업 갱신 vs Figma 이관 순서, 디자인 토큰 정의 단계 부재 (위 우선순위 참고)
10. **컷씬(정지 일러스트)과 전투(도트 픽셀아트) 화풍 혼재가 의도인지 불명** — 개발 파이프라인 2단계(Aseprite 도트)와 4장 인트로 컷씬 스펙(일러스트)이 서로 다른 아트 스타일.
11. **엔진 후보(Pixi.js/Phaser/Unity) 선택이 단순 구현 디테일이 아니라 아키텍처 전체를 좌우함** — Unity 선택 시 [[캔버스-렌더링-기술스택-조사]]의 DOM+Canvas 레이어링 결론 전체가 무효화되는데, 로드맵은 이 파급력을 언급 안 함.

## 수치/밸런스 관점 상세 (2차)

1. **전투력 공식 변수 대부분 미정의** (BaseStat 곡선/장구%/무공%/문파특전 테이블 없음) (위 우선순위 참고)
2. **장구 강화 단계(+N)의 스탯 % 효과 자체가 미정의** — 성공확률·비용 곡선만 있고 "+N당 몇 % 상승"이 없어 전투력 공식의 해당 항을 못 채움.
3. **강화 효과 이중 계산 위험** — 강화(+N)가 ItemLevel을 올리는지, 순수 가산버프로만 반영되는지 불명 — 둘 다 반영되면 같은 강화가 두 번 곱해짐.
4. **무공 노드/캡스톤의 % 효과값 미정의** — 내공 비용 곡선만 있고 "Lv50 대성 시 ATK +X%" 같은 실제 효과값이 없음.
5. 장구 슬롯 개수 3중 불일치 (8 vs 9 vs 6단순화) (위 우선순위 참고)
6. **`BaseStat = ItemLevel × Coeff × SlotWeight × GradeMultiplier`에서 ItemLevel/Coeff 정의 부재** — GradeMultiplier만 등급표로 확정, 나머지 둘은 값도 정의도 없음.
7. **캐릭터 레벨→기본 스탯 변환 공식 부재** — 몬스터 쪽엔 `BaseHP(N)=BaseHP(1)×1.8^(N-1)`이 있는데 플레이어 쪽 대응 공식이 없어 밸런싱 시뮬레이션을 몬스터만 계산 가능.
8. **전투력 예시표 대1→대2 구간만 성장률(×2.5)이 다른 전 구간(×1.78~1.81)과 다름** — 튜토리얼 배려인지 오기인지 확인 필요.
9. 내공 획득 곡선 자체가 스테이지 문서에 없음 (위 우선순위 참고)
10. **문파 특전 전체 테이블 부재로 환골탈태 대비 가성비 격차 불명** — 지금까지 공개된 예시 2개(Lv10 +3%, Lv20 +2%) 합이 5% 남짓인데, 환골탈태는 리셋 1회(수 분~수십 분)로 +15%. 전체 테이블이 채워지면 격차가 더 벌어질지 완화될지 확인 필요.
