# 무림인 키우기 — 모바일 디자인 방향

2026-09-13 탐색 시안. [[모바일-UX-개선-기획서]]의 세로형·하단 5탭 구조를 시각화한다. [동작하는 화면 시안](./모바일-화면-시안.html)에서 전투·무공·장비·문파·상점을 전환할 수 있다. 여기의 수치는 화면 밀도와 위계 확인을 위한 예시다. 게임 로직과 연결되지 않았다.

## 중심 아이디어

**‘산채의 무대와 수련 기록장’.** 전투는 어두운 배경 위에 캐릭터가 선 무대처럼 보이고, 성장 화면은 정보를 손으로 넘겨 보는 기록장처럼 정돈한다. 먹색·갈색 면으로 깊이를 만들고 금색은 선택 상태와 주요 행동에만 사용한다. 장비 등급색과 체력색은 금색과 경쟁하지 않도록 기능이 필요한 자리에서만 쓴다. 시안의 캐릭터와 배경은 프로젝트 런타임 에셋을 참조한다.

전투 첫 화면은 공통 신분줄·재화, 챕터/스테이지, 적 체력, 캐릭터, 내 체력, 다음 행동 순서다. 캐릭터를 가장 큰 시각 요소로 두고 이름과 수치가 무대 위를 덮지 않는다. 성장 화면은 44px 전투 요약줄 다음에 제목·관련 재화·선택기·내용 카드를 배치한다. 장비 페이퍼돌은 화면 폭을 쓰고 슬롯 비교는 하단 상세창으로 연다. 화면 밖 설명보다 게임 화면을 먼저 보여주고, 모바일에서는 앱이 화면 전체를 차지한다.

| 역할 | 값 | 쓰임 |
|---|---|---|
| 바탕 `ink` | `#111013` | 앱 기본 배경 |
| 표면 `surface` | `#1b191a` | 일반 카드 |
| 떠 있는 표면 `surface-raised` | `#242122` | 버튼·시트 |
| 구분선 `line` | `#51463d` | 카드·영역 경계 |
| 주 텍스트 `paper` | `#eee2cb` | 본문·제목 |
| 보조 텍스트 `muted` | `#b6a994` | 설명·보조 수치 |
| 강조 `gold` | `#d9af68` | 현재 선택·핵심 수치 |

| 이득 `green` | `#9ec69a` | 능력치 상승·전투 상태 |
| 정보 `blue` | `#87abc9` | 향후 중립 정보 |

기존 장비 6등급의 명칭·색은 [[장구-시스템]]이 기준이다. 일반 화면의 금색과 등급색을 같은 의미로 쓰지 않는다. 배경 이미지의 갈색은 UI 바탕과 혼동되지 않도록 전투 영역에서만 사용한다.

글꼴은 기기 기본 한국어 산세리프로 정보 밀도를 확보하고, 큰 장 제목과 장면 이름에만 한국어 명조/바탕 계열을 쓴다. 외부 폰트 다운로드 없이 작동하는 초안이다. 본문 16px, 설명 13~14px, 탭 이름 12px, 화면 제목 25px를 기준으로 한다. 제작 단계에서는 200% 글자 확대와 작은 화면에서 줄바꿈을 검증한다.

간격은 4/8/12/16/24px 리듬을 기본으로 한다. 누르기 영역은 최소 48px로 설계한다. 390px에서 앱은 화면 폭을 쓰고, 큰 화면에서는 최대 480px의 세로 프레임으로 중앙에 놓는다. 모서리는 카드에 거의 쓰지 않고, 상태 알약·하단 시트 손잡이처럼 용도가 분명한 요소에만 쓴다.

## 공통 컴포넌트

| 컴포넌트 | 모양과 상태 | 적용 화면 |
|---|---|---|
| 상단 신분줄 | 도호·경지·문파 정보, 내 정보·설정 진입 | 전체 |
| 재화줄 | 전·내공·영약을 작은 화면에서도 한눈에 확인 | 전체 |
| 설정창 | 전투 일시정지/재개와 효과음 켜기/끄기 | 전체 |
| 전투 요약줄 | 스테이지·실행 상태·전투 보기 | 성장 4탭 |
| 하단 5탭 | 한자 글리프 + 한글 이름, 활성 탭 위쪽 금색 선 | 전체 |
| 주요 버튼 | 밝은 금색 면, 어두운 글씨 | 다음 행동·구매·연마 |
| 보조 버튼 | 어두운 면, 밝은 글씨, 갈색 테두리 | 사냥터·비교·분해 |
| 성장 카드 | 단계·이름·레벨·효과·비용·행동을 위에서 아래로 | 무공·문파 |
| 하단 상세창 | 금색 상단 경계, 제목·비교/소비 내용·확인 | 장비·기부·일괄 행동 |

전투가 멈췄거나 보스 확인을 기다릴 때는 요약줄에서 상태를 글자로 알려야 한다. 색이나 아이콘만 바꾸지 않는다. 잠긴 탭은 자리와 이름을 유지하되 상태 설명을 열 수 있게 한다. 확인창은 취소와 실행을 분리하고, 소비 합계를 버튼 바로 위에 둔다.

## 화면별 디자인 판단

**전투:** 기존 960×540을 축소한 캔버스가 아니라 세로 화면의 독립 무대다. 실제 구현에서 공격 모션의 공통 프레임이 잘리지 않도록 가로 안전 범위와 바닥선을 다시 맞춘다. 시안은 대기 프레임 한 장을 임시로 보여줄 뿐 모션 검수 결과가 아니다. 주인공 왼쪽, 적 오른쪽 배치와 응시 방향은 [[캐릭터-이미지-생성-지침]]을 따른다. 전투 화면에서 별도 일시정지 버튼을 두지 않고, 우상단 설정창에서 정지와 재개를 한다. 정지 상태는 전투 화면과 성장 화면의 요약줄에 함께 표시한다.

**무공:** 하나의 선택 보드를 보여주고 다른 보드는 선택기로 연다. 가장 가까운 연마를 밝은 카드로 강조한다. 1회와 여러 회 행동은 버튼 이름에 실제 횟수와 총비용을 쓴다. 전체 내공 연마는 화면 아래 별도 버튼이다.

**장비:** 9슬롯을 캐릭터 주위에 배치하되 슬롯 이름을 남긴다. 소지품은 2열로 훑고, 정확한 스탯 비교와 강화 위험은 하단 상세창에서 읽는다. 슬롯과 캐릭터가 겹치지 않는지는 실제 각 장비 슬롯명·긴 아이템명으로 구현 검수한다.

**문파:** 소속과 누적 성장, 사용 가능 기여도를 먼저 분리한다. 기부 버튼은 ‘전량’과 획득 기여도를 명시한다. 문파무공은 무공 탭으로 연결한다.

**상점:** 일반상점과 기연 소탭을 같은 화면에 둔다. 한 화면에는 현재 보유 재화와 구매 비용을 함께 둔다. 확률 정보는 기연의 구매 버튼 바로 아래 둔다. 현재 실제 비용·천장·교환 횟수는 구현 데이터를 사용해야 한다.

## 모션과 접근성

탭 전환은 짧은 명도 변화로 현재 위치만 강조한다. 일반 타격·성장 성공의 시각 효과는 전투 아트가 주도하고 UI는 작게 반응한다. 보스 결과와 환골탈태만 별도 큰 연출을 허용한다. `prefers-reduced-motion`에서는 장식 움직임을 생략한다.

시안의 하단 상세창은 형태와 정보 순서를 보여주는 용도다. 실제 적용 시 초점 가두기·닫은 뒤 초점 복귀·시트 내부 스크롤·키보드 대응을 추가한다. 설정창은 닫기·배경 탭·Escape로 닫을 수 있고, 설정창을 닫아도 전투 정지 상태는 바뀌지 않는다. 금색 강조와 등급색은 텍스트·이름과 함께 사용한다. 밝은 글자 대비와 버튼 크기는 실제 기기에서 검수한다.

## 다음 제작 조건

전투가 탭 전환으로 멈추지 않게 실행 수명을 분리하거나 단일 캔버스를 유지해야 한다. 시안의 예시 수치를 실제 스토어 값으로 바꾸고, 실제 장비 스탯·강화 확률·무공 노드 비용·상점 확률을 연결해야 한다. 320/360/390/430px에서 긴 한국어 이름, 200% 글자 확대, 보스 확인창, 키보드, 회전, 안전 영역을 확인한다.
