# 위키 색인

## Concepts

- [[모바일-UX-개선-기획서]] — 2026-09-14 갱신. 세로형·하단 4탭, 무공 메인 상단의 낮춘 전투 영역과 그 아래 독립 스크롤, 무대 위 사냥터 선택, 보스/보상/비교 중앙 팝업, 성장·장비·문파·상점·환골탈태 흐름 및 검수 기준. 구현 완료 UI와 실제 기기·신규 아트의 진행 중 검수를 분리해 기록.

- [[모바일-디자인-진행-현황]] — 2026-09-14 신규. 모바일 UI 작업별 완료 기준과 완료/진행 중 상태를 관리한다.

- [[스테이지-배경-제작-현황]] — 2026-09-15 신규. 대1~10 SD 전투 배경 원화와 대별 런타임 WebP 적용 현황, 대11~30 제작 필요 범위를 관리한다.

- [[모바일-디자인-에셋-제작-명세]] — 2026-09-16 갱신. 현재 구현된 무공 전투·4탭·장비/문파/상점/스토리 흐름을 기준으로, 적용된 혈랑채 640×390 배경의 검수, 새 목현/대1 적 4종의 캐릭터별 단일 시트 5개(20모션), 대2~30 전투 아트, 공통·화면별 UI와 컷신 자산의 P0~P2 제작 범위·검수 기준.

- [[모바일-비주얼-디자인-제작-계획]] — 2026-09-16 갱신. 방치형 게임 화면 레퍼런스를 무협 SD 페인터리 톤으로 해석하고, 대1 배경 적용·대2 이후 적 플레이스홀더·대1~30 스토리 트리거와 목현 v2 네 전투 상태의 6·9·9·8프레임 PNG/JSON/GIF 검수, 목현/혈랑채 두목 대기 원화 후보 상태를 반영한 공통 UI 키트·화면별 아트 제작 순서와 모바일 검수 기준.

- [[캐릭터-이미지-생성-지침]] — 2026-09-16 갱신. 주인공·적 공통 2.5등신 SD 그림체, 투명 PNG와 공통 프레임·방향별 중심축, 640×390 캔버스 배치에서 역산한 캐릭터 크기(표시 셀 384px·신체 256px, 그 2배인 768px 셀·512px 신체로 생성, 루트 81.25%), 캐릭터당 모든 모션 단일 파일(태그 구분, 런타임 4096px 이하), 트림 패킹·프레임별 복원 좌표와 기준점 계산, 추출 스프라이트 시트 분석 절차, 도트 스프라이트 제작 시 nearest·정수배 고려사항, 프레임별 고유 동작 기준, 9프레임 공격 역할표, 정상·저속 GIF 및 실제 게임 배율 검수 규칙.

- [[캐릭터-에셋-검수-현황]] — 2026-09-16 갱신. 모든 캐릭터의 공통 검토 체크리스트에 프레임별 역할·실루엣·관절·무기 변화와 정상·저속 GIF 검수를 추가하고 목현 v2 중간 프레임을 새 기준으로 재검토하도록 분류.
