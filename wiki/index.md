- [[스토리보드-기획서-챕터2]] — 2026-09-12 신규. 챕터1 엔딩 훅("너 역시 이곳 사람이 아니로구나")을 잇는 챕터2(대11~20) 스토리 — 천외(天外) 결사, 혈교주("문지기") 최종보스, 세계의 문. 소스테이지(11~19)별 세부 이벤트 비트 포함
- [[ux-시나리오-기획서]] — 1920x1080 화면 구성, 성장보드(무공 트리) UX, 핵심 사용자 플로우 (SVG 목업 4장 포함). 2026-09-10 보스 조우/격파 확인 다이얼로그, 무공 노드 "10연마" 버튼, 하단 액션바 "일괄 연마" 버튼, 온보딩(인트로/도호입력/첫 무공 강제 강화) 및 탭 잠금 순서 v1 코드 구현 완료
- [[스테이지-레벨링-기획서]] — 대스테이지/소스테이지 번호 체계, 난이도 곡선, 보스 규칙(현재 챕터1~2, 대1~20). 2026-09-11 사냥터 모드(이미 지나온 스테이지 반복 사냥, 자동 등반 스테이지는 그대로 유지) 코드 구현 완료, §7-3 치명타/공격속도/회피가 Σ가산버프 바깥의 별도 DPS 축임을 명시(질풍살검 보드 신설 계기). 2026-09-12 챕터2(대11~20) 보스 매핑·BaseHP 곡선 연장 추가(동일 공식 그대로 확정) — 코드는 아직 대10까지만 구현(`combat.ts` `BOSS_NAMES`/`isFinalStage`), 대11~20 연동은 구현 대기
- [[캔버스-렌더링-기술스택-조사]] — PixiJS+DOM 하이브리드 추천, 성장보드 렌더링 방식/HUD 레이어링 비교

- [[배경-아트-컨셉]] — 메인화면(청운문 대련장)·대1(혈랑채) 배경 컨셉 + 완성 SVG 2종, 대2~10/문파거점5/환골탈태 특수배경 목록. 대1 SVG는 2026-09-11 래스터화해 `assets/backgrounds/`에 임시 게임 적용(정식 이미지는 [[디자인-프롬프트-큐]] 대기 중)
- [[에셋-아트-컨셉]] — 등급 프레임 규격, 아이템 아이콘 픽셀 그리드, 보스/무공아이콘/경지뱃지7단계/문파엠블럼6/무공노드5보드/보스2~10 텍스트 스펙. 주인공은 2026-08-01 사용자 레퍼런스 이미지로 확정, 캐릭터 스프라이트는 2026-09-11부터 도트 트레이싱 폐기하고 페인터리 레퍼런스 크롭 방식으로 전환(목현·혈랑채 실제 적용 완료)
- [[디자인-프롬프트-큐]] — 외부 이미지 생성 AI용 텍스트 프롬프트 큐(캐릭터/배경/UI·이펙트), 회차별 최대 20개 우선순위 순 생성·누적(2026-09-11 5→20 상향). "현재 프로젝트 실제 적용 형태" 공통 규칙(배경 사이드뷰 시점/캐릭터 좌우 방향/페인터리 스타일/프레임 번호 금지/배경 아닌 이미지는 배경 없이 생성), 완료 시 프롬프트 본문 삭제 정책, "자체 제작 임시 에셋은 완료 아님" 규칙 포함(파일 존재만으로 완성 판정 금지). 데미지 숫자 폰트 스타일(일반/치명타/피격 3종 전부)·타격 이펙트(일반/크리티컬 2종 전부) 이미지 확보·게임 적용 완료(2026-09-11), "피격 이펙트"(빨강, 별개 독립 항목)만 대기 중 신규 등재로 남음. 캐릭터 프롬프트는 2026-09-11부터 idle/attack에 death(쓰러짐) 시트를 세 번째 필수 산출물로 추가(대기 중인 캐릭터 5건 전부 반영). "주인공(목현) idle/발도 공격 포즈 재제작" 신규 등재(대기 중, death 시트는 플레이어 사망 연출 부재로 의도적 제외) — [[에셋-아트-컨셉]] §3의 미해결 재설계 과제(직검 찌르기→발도 베기)를 구체화. 2026-09-11 "전면 재설계 프롬프트 세트" 절 신규 — 현재 게임에 렌더링되는 모든 요소(완료분 포함) 재설계 프롬프트, 캐릭터 3종(목현/혈랑채 두목·졸개)은 idle/공격1/공격2/피격/쓰러짐/승리 6시트로 확장. 혈랑채 두목/졸개 재설계 프롬프트는 "대기 중" 절에 정식 등재(기존 idle/attack 2종은 완료 상태 별도 유지). 대2 보스/잡몹 프롬프트도 동일하게 6모션으로 직접 갱신(미확보 상태라 기존 프롬프트 교체)
