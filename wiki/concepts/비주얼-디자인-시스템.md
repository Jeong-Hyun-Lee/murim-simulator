게임 전체 비주얼 톤을 **"다크 무협 HUD"**로 확정(2026-07-31). 기존 라이트 양피지 목업(`ux-시나리오-목업.html`)의 4단 표면 레이어링 구조를 뼈대로, `design/ux-목업-05-메인화면-다크리디자인.svg`의 고채도 골드·크림 텍스트·청동 라인·유리질 패널·glow 기법을 이식해 통합했다. 라이트 목업은 참고용으로만 남기고 공식 톤은 아래 다크 토큰을 따른다.

- UI/본문: `"Pretendard", "Apple SD Gothic Neo", "Noto Sans KR", system-ui, sans-serif`
- 제목/인장/랭크뱃지: `"Noto Serif KR", "Nanum Myeongjo", serif`

## 3. 컴포넌트 상태 규칙

**버튼**: `.gold`=배경`--gold`+텍스트`--bg` / `.recommend`=`--surface-glass`+보더`--gold`+glow(box-shadow 0 0 12px rgba(232,188,85,.45)) / `.disabled`=`--panel-2`+텍스트`--ink-muted`+얇은 보더 신규 추가 / `.locked`=투명+보더`--lock` / `.max`=배경 `color-mix(in srgb, #5d8f5d 45%, var(--panel-2))`+텍스트 `#d9f2c9`

**게이지**: 트랙 `--panel-2`, ok=`#6fae64`, warn=`--gold-soft`, risk=`--seal-soft`

**카드**: 기본 `--panel`+보더`--line`@.4 / 강조(마이·게인) 보더`--gold`+`color-mix(--gold 8%, panel)` / 위험(로스) 보더`--seal`+`color-mix(--seal 6%, panel)` / HUD 플로팅 카드는 `--surface-glass` 사용

**인장(seal) 모티프**: 형태·회전(-2~-3deg)·서체 유지(핵심 정체성 요소). 배경에 `color-mix(--seal 10%, transparent)` 잉크 번짐 워시 신규 추가, 선택적 `drop-shadow(0 0 6px)` 발광.

**Glow 사용 규칙**: SVG의 softGlow(8px blur)/hardGlow(4px blur) 기법을 채택하되 화면당 1~3개 요소로 제한(현재 진행 세그먼트, 추천 CTA, 핵심 강조 수치, 자동전투 토글, 선품 등급).

## 4. 등급 6단계 색 — 다크 배경 보정 규칙

등급색 값 자체는 `장구-시스템.md` 기준 절대 불변(하품`#9e9e9e`/중품`#4caf50`/상품`#2196f3`/절품`#9c27b0`/신품`#ff9800`/선품 금+무지개 발광). 다크 배경 위 시인성 보정은 색 값이 아니라 주변 처리로만:

1. 작은 요소(dot/보더)는 `box-shadow 0 0 4px color-mix(등급색 50%, transparent)` halo 추가.
2. 인벤토리 타일 배경에 `color-mix(등급색 12%, panel)` 미세 틴트(fill/border 원본색은 불변).
3. 절품(보라)은 warm-brown 배경에서 가장 탁해 보임 — glow 색상에 한해서만 밝힌 파생값(`#b455c9`) 사용, 실제 fill/border는 원본 고정.
4. 선품은 시스템 문서 명시된 발광을 gold 40% opacity, blur 10~14px로 정식 구현.

## 5. 아이콘 톤 방침 — 확정

**한자 단일 글자 인장 스타일 유지** (劍/甲/頭 등 장구 슬롯, 起/揮/刺 등 무공 노드, 壹~捌 페이지 인장). 범용 벡터 아이콘셋으로 바꾸면 장르 표준 HUD와의 차별점이 사라짐 + 별도 에셋 파이프라인 없이 유니코드 글리프로 즉시 프로덕션 적용 가능. 배지에 `radial-gradient(35% 30%, color-mix(--gold 25%, panel), panel)` 하이라이트, 글자색 `--gold`/`--gold-soft`. 발광은 해금 순간 연출용으로만 예약(평시 무발광 — 동시에 수십 개 노출 시 시각피로 방지).
