# 모바일 디자인 진행 현황

모바일 디자인 작업은 이 문서를 기준으로 완료와 진행 중 항목을 구분한다. **완료**는 코드 반영 뒤 정적 검사와 프로덕션 빌드를 통과한 항목만 기록한다. 실제 기기 검수나 신규 이미지 제작이 남은 항목은 완료로 옮기지 않는다.

## 완료

| 작업 단위 | 반영 범위 | 확인 |
|---|---|---|
| 공통 모바일 틀 | 세로형 4탭, 상단 신분/재화, 설정, 전투 요약줄 | ESLint·프로덕션 빌드 통과 |
| 전투 정보 위계 | 전투 상태/등반 배지, 체력 영역, 사냥터 버튼, 보스·이야기·전황 안내 | ESLint·프로덕션 빌드 통과 |
| 성장·상점 화면 | 무공, 장비, 문파, 일반상점/기연, 내 정보, 환골탈태의 카드·상태·행동 위계 | ESLint·프로덕션 빌드 통과 |
| 보조 흐름 | 장비 빈 상태, 잠긴 탭 목표 카드, 온보딩 장면/여정 표기 | ESLint·프로덕션 빌드 통과 |
| 재화 상세 팝업 | 재화별 수량·용도·보호부적 정보의 카드 위계 | ESLint·프로덕션 빌드 통과 |
| 장비 비교·강화 팝업 | 현재 장비·후보 장비·다음 강화의 비용/성공/실패 조건 위계 | ESLint·프로덕션 빌드 통과 |
| 기연 결과 카드 | 획득 수, 등급, 장비 부위, 다시 뽑기 행동의 위계 | ESLint·프로덕션 빌드 통과 |
| 기연 확률 팝업 | 등급 확률과 천장/10회 보장 규칙의 위계 | ESLint·프로덕션 빌드 통과 |
| 장비 분해 확인 팝업 | 선택 장비 수, 획득 보상, 되돌릴 수 없는 경고의 위계 | ESLint·프로덕션 빌드 통과 |
| 문파 전량 기부 확인 팝업 | 교환 비율, 이번 소비, 획득 기여도, 기부 후 잔액을 구분한 요약 위계 | ESLint·프로덕션 빌드 통과 |
| 로컬 UI 시각 검수 | 분리된 로컬 세션에서 온보딩 완료 뒤 재화 상세 팝업의 제목·용도·수량·보호부적 정보와 설정 팝업의 일시정지·재개 상태 전환이 세로 프레임에서 겹치지 않고 읽히는 것을 확인 | 인앱 브라우저 시각·동작 확인 |
| 장기 플레이 화면 | 수련 목표 전체 화면, 수련탑 상태·진입 행, 오프라인 보상 팝업, 설정 저장 백업 구역의 카드·행동 위계 | ESLint·프로덕션 빌드·브라우저 동작 확인 |
| UI Element 적용 후 시각 재정비 | 버튼 상태, 페이퍼돌 비율, 상점 밀도, 장식 단계, 헤더·하단 탭, 팝업 여백을 정리하고 320×568·375×812·430×932에서 화면 검수 | ESLint·프로덕션 빌드·인앱 브라우저 확인 |
| 완료 기록 체계 | 모바일 UX 기획·디자인 방향·색인·로그에 완료/진행 중 상태 분리 | 문서 링크 확인 |

## 진행 중

| 작업 단위 | 다음 완료 기준 |
|---|---|
| 실제 기기 전수 검수 | 지정 폭과 Safari/Chrome에서 긴 문구·200% 글자·키보드·회전·안전 영역 확인 |
| 전투 아트 | 목현 외 대1 적 4종과 대2 이후 적/배경을 생성·투명화·패킹·게임 적용 검수까지 통과 |
