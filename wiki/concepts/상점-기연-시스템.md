# 무림인 키우기 — 상점/기연(奇緣) 시스템

> **등급 체계는 [[장구-시스템]]의 통합 6단계(하품/중품/상품/절품/신품/선품)를 그대로 따른다.** 아래 확률표도 이 6단계 기준으로 갱신됨(2026-07-27, 기존 4단계 일반/희귀/영웅/전설 표는 폐기).

## 서사

상점 하위 탭을 각기 다른 저잣거리 상인/장소로 의인화한다.

- **비급 거래상** — 무공 구매/해금 창구. "어느 낙향한 학사가 필사해 판다는 소문의 비급들." 문파에서 정식으로 배우지 못한 무공을 암시장에서 구하는 구조.
- **저잣거리 대장간** — 장구 구매/강화 창구. 대장장이 노(老)씨가 "쇠는 두드릴수록 강해지는 법"이라며 강화 재료를 받고 병기를 벼려줌.
- **기연(奇緣)** — 가챠. "우연히 기연을 만나 절세 무공/영약/신병을 얻는다"는 무협 클리셰를 뽑기 연출에 매핑. "오늘 강호를 떠돌다 보니 묘한 인연이 닿는다"는 도입 문구.

**기연 결과 플레이버 텍스트 예시:**

- *(하품)* "낡은 폐가 마루 밑에서 녹슨 단검 한 자루를 주웠다. 대단한 물건은 아니지만, 없는 것보단 낫겠지." — 범병(凡兵, 하품) 획득
- *(상품)* "산길에서 정신을 잃고 쓰러진 노도사를 구해주었더니, 그가 품에서 낡은 죽간(竹簡) 하나를 건네고 홀연히 사라졌다." — 영병(靈兵, 상품) 무공서 획득
- *(선품)* "벼락 맞은 고목 아래 파묻혀 있던 함(函)을 열자 서늘한 검광이 뿜어져 나왔다. 검신에 새겨진 글씨: '주인을 기다린 지 백 년.'" — 신병이기(神兵利器, 선품) 획득, 강호에 소문이 돈다

## UX

**서브탭 구성:** [일반상점] / [기연(奇緣)]

**일반상점:** 카테고리 탭(재화/소모품/특별패키지), 카드형 그리드(아이콘+수량+가격+[구매] 버튼, 활성/비활성 규칙 재사용). 실결제 상품은 구매 확인 다이얼로그 필수.

**기연(가챠):**

```
┌──────────────────────────────────────────────────────────────────┐
│   [배너 캐러셀: 이번 기연 — "매화검 비급 확률 3배"]                 │
│               ┌──────────────┐                                    │
│               │  기연함 (연출)│   ← 클릭 시 뽑기 연출 재생          │
│               └──────────────┘                                    │
│        [1회 뽑기 · 영약 100]     [10회 뽑기 · 영약 900 (10%↓)]     │
│   천장(보장): 90회 내 신품 이상 확정 · 진행 62/90  ▓▓▓▓▓▓░░░        │
│   확률 정보 보기 ▸ (법정 고지 링크)                                 │
└──────────────────────────────────────────────────────────────────┘
```

10회 뽑기는 할인율과 함께 무공 탭 "10연마" 버튼과 동일한 일괄 처리 UX 문법 재사용. 천장 게이지 상시 노출(신뢰성 확보). 확률 표시는 뽑기 버튼 바로 아래 "확률 정보 보기" 링크로 상시 고정 배치(1클릭 이내 도달), 배너에도 핵심 확률 소형 텍스트 병기.

**뽑기 결과 연출 (등급별 차등):**

| 등급 | 연출 |
|---|---|
| 하품/중품 | 즉시 카드 뒤집힘, 짧은 흰색 반짝임(0.3초) |
| 상품 | 파란 빛 확산 + 카드 확대 팝업 |
| 절품 | 보라 파티클 + 화면 살짝 어두워짐 + 클로즈업 |
| 신품 | 주황 광선 + 화면 진동 + 슬로우모션 카드 오픈 |
| 선품 | 풀스크린 금빛/무지개 연출 + 암전 후 스포트라이트 + 파티클 폭죽 + 대형 획득 텍스트 |

10연속 결과는 그리드로 순차 뒤집히며 표시, 최고 등급 카드는 마지막에 몰아서 강조(가챠 게임 관례). 결과 화면 하단 [계속하기]/[한번 더], 신규 비급 획득 시 "신규 무공 보드 해금!" 배너(보스 보상과 동일 패턴 재사용).

## 수치

**비용:**

| 횟수 | 비용(영약) | 비고 |
|---|---:|---|
| 1회 | 100 | |
| 10회 | 900 | 10% 할인, 상품 이상 1회 확정 보장 |

**등급별 확률표 (통합 6단계):**

| 등급 | 확률 | 비고 |
|---|---:|---|
| 하품 | 55% | 장구/강화석 위주 |
| 중품 | 30% | |
| 상품 | 12% | |
| 절품 | 2.5% | 세트효과 보유 |
| 신품 | 0.45% | |
| 선품 | 0.05% | 천장 전용 사실상 확정 등급 |

**천장(보장) 시스템:**
- 소프트 천장: 75회부터 선품 확률 선형 증가(76회째부터 매 회 +0.5%p)
- 하드 천장: 90회 이내 미획득 시 90회째 확정 선품 지급, 카운터 초기화
- 10연차 보장: 10회 뽑기 시 상품 이상 최소 1개(하위 등급만 나오면 마지막 슬롯을 상품으로 승격)
- 천장 카운터는 영구 유지(환골탈태로도 초기화되지 않음) — 프레스티지와 가챠 진행을 분리해 장기 유저 이탈 방지

**영약 공급처 (2026-07-27 신규 정의):** 이전까지 영약은 소모처(가챠/문파기부/장구강화)만 있고 공급처가 없었다. 아래로 공급을 명시한다.

| 획득처 | 수량 | 주기 |
|---|---:|---|
| 대보스(X-10) 확정 지급 | 3개 | 대스테이지당 1회(최초 클리어) |
| 소보스(X-5) 확률 지급 | 1개 (30% 확률) | 소스테이지 클리어 시 |
| 일일 출석 보상 | 5개 | 1일 1회 |
| 문파 토벌전(주간 보스) 보상 | 20개 | 주 1회 |
| 일반상점 구매 | 가변 | 실결제/전(錢) 교환 |

일 평균 기대치 ≈ 15~25개/일(챕터1 초중반 파밍 속도 기준) — 1회 뽑기(영약 100) 기준 약 4~7일에 1회 수준으로 설계, 가챠가 "가끔 하는 이벤트"로 기능하도록 함.

## v1 구현 범위 (2026-09-10, 2026-09-10 장구 인벤토리 도입으로 갱신)

인벤토리·결제 인프라가 없는 v1에서 아래로 축소 구현했다(상세는 `src/game/shopData.ts`, `src/game/gachaData.ts` 주석 참고):

- **일반상점**: 재화/소모품/특별패키지 3개 카테고리 중 "전(錢)→영약 교환" 1종만 구현. 위키에 교환 비율 수치가 없어 무기 강화 비용과 동일한 체증 곡선으로 근사 신규 정의 — `BaseCost 500 × 1.2^구매횟수`(전 단위, 영약 1개당). 실결제 특별패키지는 결제 인프라 부재로 범위 밖.
- **기연 결과 연출**: 파티클/화면 진동 등 캔버스 이펙트 대신, 등급별 카드 테두리 색상(장구-시스템 6단계 색상 그대로) + 신품 이상 글로우 강도 차등으로 단순화 구현.
- **기연 보상(2026-09-10 갱신)**: 장구 인벤토리 도입 전에는 등급 배율을 곱한 내공으로 대체 지급했으나, 인벤토리가 생긴 뒤로는 위키 플레이버 텍스트("영병 무공서 획득" 등)대로 실제 장구 아이템(등급 확정, 슬롯 랜덤)을 지급하도록 변경.
- 천장/확률표/10연차 보장은 위키 수치 그대로 이미 구현되어 있었음(변경 없음).
