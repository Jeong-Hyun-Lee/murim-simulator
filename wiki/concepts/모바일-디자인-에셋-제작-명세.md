# 모바일 디자인 에셋 제작 명세

[[모바일-UX-개선-기획서]]와 [[모바일-디자인-방향]], [동작 시안](../design/모바일-화면-시안.html)을 실제 게임 화면으로 옮기기 위한 시각 자산 목록이다. 기준 화면은 세로형·하단 4탭이며, 무공 메인 상단의 낮춘 전투 영역에 사냥터 선택을 겹쳐 놓고 전투 일시정지/재개는 우상단 **설정창 안**에 둔다. 2026-09-14의 `assets/`, `src/canvas/BattleCanvas.tsx`, 게임 데이터와 시안을 대조했다. 시안의 문자·이모지·CSS 모양은 제작 완료된 아트로 세지 않는다.

## 1. 범위와 현재 보유분

| 자산 | 현재 상태 | 제작 판단 |
|---|---|---|
| 캐릭터 | 목현, 혈랑채 두목·졸개·궁수·정예산적 5종의 런타임 모션 시트 27개 | 현재 것은 임시 자산. **5종 모두 외형과 현행 동작 구성 27모션 시트/155프레임을 신규 제작**해 교체한다. 기존 시트는 동작·타이밍 참고용이다. |
| 전투 배경 | `assets/backgrounds/stage1~10-*.webp` 10장(1280×780, 640×390 전투 스트립의 2배). 대마다 고유 배경을 쓰고 대11~30은 대10 배경을 임시 사용 | 대1~10 배경은 런타임 적용 완료([[스테이지-배경-제작-현황]]). 대11~30의 고유 배경은 아직 없다. 대31~40은 기획 단계다. |
| 전투 효과·숫자 | 일반/치명타 타격 효과 2종과 데미지 숫자 이미지 보유 | 모바일 표시 배율·배경 대비·프레임 경계를 검수한 뒤 재사용한다. |
| 공통 UI 그림 | 전용 파일 없음. 시안의 4탭은 `武/甲/門/錢`, 재화는 `錢/氣/丹`, 설정·프로필은 인라인 SVG | 같은 선 굵기와 시점의 정식 아이콘 세트가 필요하다. |
| 장비·무공·문파·상점 그림 | 전용 파일 없음. 시안은 문자와 CSS 카드·배너로 표현 | 아래의 최소 아이콘/문장/상품 그림을 제작한다. 카드·테두리·진행바는 CSS 중심으로 구현한다. |
| 글꼴 | 전투 숫자용 비트맵 이미지는 있으나 UI 전용 한글 폰트 파일 없음 | 본문은 현재의 기기 기본 글꼴을 우선 사용한다. 장 제목 전용 서체 도입은 사용권·용량·한글 가독성 확인 후 결정한다. |

이 문서의 **P0**는 현재 시안의 무공 메인 전투·성장 영역과 하단 4탭을 모바일 실화면으로 만들 때 필요한 자산, **P1**은 실제 게임의 모든 기능 화면을 같은 품질로 마무리할 때 필요한 자산, **P2**는 대2~30과 이야기의 고유 장면 확장이다. 혈랑채 배경은 P0 신규 원화가 런타임에 적용됐고, **기존 목현·대1 적 4종은 P0 신규 제작 필수**다. 타격 효과·숫자처럼 별도 지정이 없는 기존 이미지만 실측 후 재사용할 수 있다.

### 구현과 제작 범위의 구분

- **구현 완료:** 무공 메인의 낮은 전투 무대, 사냥터 선택 오버레이, 설정창 안 일시정지, 4탭, 장비·문파·상점·기연의 기능 흐름, 대1~30 스토리 카드·자막·컷신 트리거.
- **런타임 아트 적용:** 대1~10 전투 배경, 대1 캐릭터 5종의 기존 스프라이트, 일반/치명타 타격 효과와 데미지 숫자. 이 중 배경은 신규 원화 적용 상태이며, 캐릭터는 교체 대상이다.
- **플레이스홀더:** 대2 이후 적은 전투 캔버스에서 도형으로 표시된다. 대2~30 적과 대11~30 고유 배경은 아직 연결된 아트가 없다.

## 2. 화면 공통 제작 목록

| 영역 | 제작할 요소 | 수량·표현 | 우선순위 |
|---|---|---|---|
| 하단 이동 | 무공·장비·문파·상점 | 의미가 바로 읽히는 아이콘 4종. 선택/일반/비활성은 색과 선으로 처리하고 이름을 항상 병기 | P0 |
| 상단 신분 | 내 정보·설정·경지 표식 | 기능 아이콘 2종, 경지는 후천~생사경 6단계의 표식 또는 공통 문양+텍스트 규칙. 이후 `등봉조극 n중`은 반복 생성 가능한 표시 | P0/P1 |
| 재화와 재료 | 전·내공·영약, 강화석·보호부적, 문파 기여도 | 서로 헷갈리지 않는 기본 픽토그램 6종. 전투 EXP/레벨은 숫자·게이지로 표현하고 필요할 때만 별도 표식 | P0/P1 |
| 조작 | 뒤로·닫기·펼침·잠금·정보·정렬·비교·전투 보기·사냥터·알림 | 작은 기능 아이콘 묶음. 행동명 텍스트를 지우지 않는다 | P0/P1 |
| 설정 | 효과음 켜짐/꺼짐, 전투 일시정지/재개 | 설정창 안의 **텍스트 있는 버튼·토글 상태**로 설계. 전투 화면 별도 일시정지 아이콘은 제작하지 않는다 | P0 |
| 전투·결과 상태 | 자동 등반·사냥 중·일시정지·보스 대기·승리·패배·보상·잠금 | 상태색/배지/아이콘과 문구의 조합. 색만으로 상태를 전달하지 않는다 | P0/P1 |
| 공통 화면 틀 | 상단줄·재화줄·4탭 바·카드·주/보조 버튼·설정/사냥터/비교 중앙 팝업·체력/진행바·빈 상태 | 우선 CSS/벡터 토큰으로 제작. 반복되는 장식선·문양만 투명 타일 또는 9패치 이미지로 추출 | P0/P1 |

아이콘은 하나의 스타일 규칙(두께, 모서리, 명암, 금색 사용 범위)으로 제작하고, SVG 24×24 기준 원본과 화면별 실제 크기를 정한다. 누르기 영역은 아이콘의 작은 그림 크기와 별개로 최소 48×48px이다. 하단 4탭은 축소해도 형태가 구분되어야 하며, 장식 한자를 쓴다면 글자 폭·폰트별 변형에 의존하지 않는 벡터로 고정한다. 금색은 선택·핵심 행동, 장비의 6등급 색은 품질 표시로 의미를 분리한다.

## 3. 전투 무대·캐릭터·연출

### 무대 배경

- **대1 혈랑채(P0, 적용 완료):** 세로형 앱 속 전투 무대는 논리 크기 **640×390의 가로 스트립**이다. 원화 `wiki/raw/assets/hyeollangchae-battle-background-sd-v2-candidate.png`(1606×979)를 런타임 1280×780 WebP로 줄여 적용했다. 목현 왼쪽·적 오른쪽은 흙바닥 공터의 공통 바닥선(무대 높이 80%)에 서고, 무대 위 사냥터 버튼 아래로 인물이 보인다. 가로 회전 화면에서 다른 비율이 필요하면 같은 장소의 별도 구도를 납품한다.
- **대2~10(P2, 적용 완료):** 흑시장, 팽가 수련장, 비무대회장, 청운문의 밤, 관아, 심상 공간, 정파 연합 전선, 청운문 본산, 혈교 하남지단 배경을 같은 1280×780 규격·80% 바닥선으로 적용했다. 목록은 [[스테이지-배경-제작-현황]]에서 관리한다.
- **대11~20(P2):** 혈교 잔당 추적, 장강 수로채, 남궁세가, 화산파, 혈교 장로 거점, 천외 술법 공간, 타락한 전이자 구역, 정사대전, 혈교 총단 관문, 세계의 문/혈교주 결전의 배경 각 1장. [[스토리보드-기획서-챕터2]]를 기준으로 한다.
- **대21~30(P2):** [[스토리보드-기획서-챕터3]]의 총단 폐허부터 개천대 정상까지 대스테이지별 1장씩 제작한다. 대31~40은 [[스토리보드-기획서-챕터4]] 코드 반영 이후 별도 묶음으로 시작한다.
- **총량:** 현재 구현 범위 기준 대스테이지별 1구도 **30장**이다. P0 대1 혈랑채 1장은 적용했고, P2 대2~30의 고유 장면 29장을 제작한다. 시간대·날씨·보스용 변주는 별도 범위 확정 전 필수 수량에 넣지 않는다.

배경에는 체력 바·버튼·문구를 그려 넣지 않는다. 세로 화면의 실제 전투창과 가로 960×540 화면을 각각 작게 축소해 실루엣, 바닥선, 텍스트 가독성, 캐릭터와 배경의 명도 분리를 검수한다. 한 장의 가로 그림을 기계적으로 자르는 방식으로 납품하지 않는다.

### 캐릭터와 초상

- **즉시 제작(P0):** 목현 1종과 혈랑채 졸병·궁수·정예산적·두목 4종을 모두 **새 외형부터 새 모션 시트까지** 제작한다. 주인공은 왼쪽에서 오른쪽을, 적은 오른쪽에서 왼쪽을 바라본다. 모두 약 2.5등신 SD 페인터리로 통일하고, 적의 방향을 좌우 반전으로 맞추지 않는다. 기존 이미지는 승인된 새 캐릭터의 대체 납품물이 아니다.
- **전체 콘텐츠(P2):** 현재 코드에는 대1~30의 보스·졸개·변형·정예 배치와 이름이 있고, 대31~40은 기획 로스터가 준비됐다. 대1 이후 적은 아직 스프라이트로 연결되지 않았으므로 대2~30은 대스테이지별 대표 졸개와 보스를 우선 제작하고, 변형·정예는 [[스테이지-적-구성-연출-기획서]] 3절의 파생 외형 규칙으로 확장한다. 대31~40은 코드 반영 후 같은 규칙으로 산정한다.
- **모션 기준:** 현행 동작 구성은 목현·대1 두목 각 6모션, 나머지 대1 적 각 5모션으로 **P0 신규 27모션 시트·155프레임**이다. 후속 캐릭터 수량과 모션 시트 수는 파생 외형 범위가 확정된 대스테이지 단위로 산정한다. 신규 제작 시 [[캐릭터-이미지-생성-지침]]의 실제 투명 PNG, 약 2.5등신, 공통 프레임·여백·기준점·방향과 캐릭터별 전체 모션의 최대 범위 검수를 적용한다.
- **초상·대화(P1/P2):** 내 정보의 목현 초상은 **새로 제작해 검수한** 스프라이트에서 안전하게 크롭할 수 있는지 확인한다. 보스 확인창·대화창도 새 전투 원화에서 얼굴 컷을 파생할 수 있는지 시험한 뒤, 읽히지 않는 인물만 초상 원화를 별도 제작한다. 동료/NPC 전신이나 컷신은 현재 시안의 필수 구성에 없으므로 스토리 화면 범위가 정해질 때 수량을 확정한다.

현재 일반·치명타 타격 효과와 숫자 이미지는 신규 제작 항목이 아니라 **모바일 배율 검수 항목**이다. 맞는 효과가 없는 피격·승리·패배·환골탈태 전환은 UI 애니메이션만으로 읽히는지 먼저 시험하고, 부족한 장면에만 전용 효과를 만든다. 번쩍임·흔들림은 움직임 감소 설정에서도 상태 문구로 결과를 확인할 수 있어야 한다.

## 4. 성장·장비·문파·상점

| 화면 | 제작할 그림·문양 | 합리적인 제작 단위 | 우선순위 |
|---|---|---|---|
| 무공 | 보드 표식, 초식 단계 문양, 연마/대성/잠금 표시 | 현재 보드 7개에 식별 표식 7종. 각 6노드=42개를 모두 별도 그림으로 만들 필요는 없고, 노드 단계·상태는 공통 도형과 텍스트로 표현 | P0/P1 |
| 장비 | 무기·몸통·머리·팔·발·허리·목·반지 슬롯 표식, 강화석·보호부적, 등급 프레임 | 데이터상 9슬롯이지만 반지 L/R은 같은 계열 그림을 공유하므로 슬롯 기본 그림 **8종**+좌우 위치 표기. 6등급은 색·테두리 규칙으로 구분하고, 개별 아이템마다 실루엣이 필요한지 데이터/상품 구성 확정 후 결정 | P0/P1 |
| 문파 | 청운문 문장·현판/배너, 기여도·문파 단계 표식 | 현 게임은 청운문 소속 고정이므로 우선 문장 **1종**. 기획상 가입 가능 문파 6곳의 나머지 문장은 실제 선택/등장 화면 범위가 정해지면 제작 | P0/P2 |
| 일반상점 | 영약 병 상품 그림, 교환 완료 표시 | 거래 상품은 현재 영약 1종이므로 상품 그림 **1종**. 화폐·보유량은 공통 재화 아이콘 재사용 | P0 |
| 기연 | 기연 뽑기 상징, 결과 카드 뒷면/등급 드러남, 장비 결과 썸네일 | 상징·공통 카드 각각 1종. 6등급 결과는 색/테두리/짧은 효과로 분기하고, 장비 썸네일은 장비 기본 그림을 재사용 | P1 |
| 환골탈태·보스 결과 | 환골탈태 문양, 전/후 비교, 보스 승리·보상 표식 | 공통 문양·결과 틀을 우선 설계. 단계별 다른 전신 그림·대형 컷신은 스토리 연출 범위 확정 후 제작 | P1/P2 |

장비 아이콘은 실제 인벤토리의 `slot + grade + itemLevel + enhanceLevel` 조합과 맞춰야 한다. 이름만 다른 동일 슬롯 장비에 임의의 유일 원화를 약속하지 않는다. 페이퍼돌 중앙의 목현은 별도 정지 그림보다 **신규 제작한** 대기 모션/대표 프레임을 먼저 사용한다. 아이콘, 카드, 등급 테두리가 합쳐졌을 때 320px 화면에서도 장비 이름과 강화 수치가 읽혀야 한다.

## 6. 제작 순서와 완료 판정

1. **P0 시안 실전화:** 디자인 토큰·4탭/재화/설정 아이콘, 무공 메인 상단의 대1 혈랑채 배경(적용 완료·모바일 실측 필요), **새 목현·적 4종의 27모션 시트/155프레임**, 기존 타격 효과·숫자의 모바일 실측, 무공 7보드 식별표식, 장비 8계열 기본 아이콘, 청운문 문장, 영약 상품 그림. 사냥터 선택이 무대 상단에 겹치고 독립 일시정지 버튼 없이 설정창에서 정지·재개가 작동하는 화면을 기준으로 시각 검수한다.
2. **P1 전체 기능 품질:** 사냥터·보스 확인·결과·환골탈태·기연·첫 접속 3장·각종 빈 상태와 모달, 재료·상태 아이콘을 확정한다. 모든 4탭과 연결된 상세창에서 모양·표기·색의 의미가 같아야 한다.
3. **P2 콘텐츠 확장:** 대2~30의 배경 29장과 적을 스토리/전투 적용 순서로 제작하고, 대31~40은 구현 시 같은 묶음으로 확장한다. 단순히 파일만 쌓지 않고 각 스테이지에서 이름, 등장 그림, 모션, 배경이 맞는지 확인한다.

디자인 완성의 판정 기준은 파일 개수가 아니라 **실제 모바일 화면에서 캐릭터·배경이 잘리지 않고, 4탭과 설정/결과/성장 상태가 일관되며, 각 스테이지의 고유 이름과 그림이 일치하는 것**이다.
