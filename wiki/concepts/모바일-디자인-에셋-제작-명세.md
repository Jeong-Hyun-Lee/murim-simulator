# 모바일 디자인 에셋 제작 명세

[[모바일-UX-개선-기획서]]와 [[모바일-디자인-방향]], [동작 시안](../design/모바일-화면-시안.html)을 실제 게임 화면으로 옮기기 위한 시각 자산 목록이다. 기준 화면은 세로형·하단 5탭이며, 전투 일시정지/재개는 우상단 **설정창 안**에 둔다. 2026-09-13의 `assets/`, `src/canvas/BattleCanvas.tsx`, 게임 데이터와 시안을 대조했다. 시안의 문자·이모지·CSS 모양은 제작 완료된 아트로 세지 않는다.

## 1. 범위와 현재 보유분

| 자산 | 현재 상태 | 제작 판단 |
|---|---|---|
| 캐릭터 | 목현, 혈랑채 두목·졸개·궁수·정예산적 5종의 런타임 모션 시트 27개 | 재사용 후보. 세로 무대에서 크기·여백·방향·투명도·2.5등신 그림체를 다시 검수한다. 파일 존재만으로 최종 품질 통과로 보지 않는다. |
| 전투 배경 | `assets/backgrounds/stage1-hyeollangchae.png` 1장, 960×540 가로형. 시안과 런타임 모두 대1~20에 같은 장면 사용 | 대1 혈랑채의 세로 구도 원화 또는 안전하게 재구성한 확장판이 최우선. 대2~20의 고유 배경은 아직 없다. |
| 전투 효과·숫자 | 일반/치명타 타격 효과 2종과 데미지 숫자 이미지 보유 | 모바일 표시 배율·배경 대비·프레임 경계를 검수한 뒤 재사용한다. |
| 공통 UI 그림 | 전용 파일 없음. 시안의 5탭은 `⚔/武/甲/門/錢`, 재화는 `錢/氣/丹`, 설정·프로필은 인라인 SVG | 같은 선 굵기와 시점의 정식 아이콘 세트가 필요하다. |
| 장비·무공·문파·상점 그림 | 전용 파일 없음. 시안은 문자와 CSS 카드·배너로 표현 | 아래의 최소 아이콘/문장/상품 그림을 제작한다. 카드·테두리·진행바는 CSS 중심으로 구현한다. |
| 글꼴 | 전투 숫자용 비트맵 이미지는 있으나 UI 전용 한글 폰트 파일 없음 | 본문은 현재의 기기 기본 글꼴을 우선 사용한다. 장 제목 전용 서체 도입은 사용권·용량·한글 가독성 확인 후 결정한다. |

이 문서의 **P0**는 현재 시안의 전투·성장 5탭을 모바일 실화면으로 만들 때 필요한 자산, **P1**은 실제 게임의 모든 기능 화면을 같은 품질로 마무리할 때 필요한 자산, **P2**는 대2~20과 이야기의 고유 장면 확장이다. P0 항목에 기존 이미지가 있어도 품질 검수가 남았다면 `재사용 후보`로 표시한다.

아이콘은 하나의 스타일 규칙(두께, 모서리, 명암, 금색 사용 범위)으로 제작하고, SVG 24×24 기준 원본과 화면별 실제 크기를 정한다. 누르기 영역은 아이콘의 작은 그림 크기와 별개로 최소 48×48px이다. 하단 5탭은 축소해도 형태가 구분되어야 하며, 장식 한자를 쓴다면 글자 폭·폰트별 변형에 의존하지 않는 벡터로 고정한다. 금색은 선택·핵심 행동, 장비의 6등급 색은 품질 표시로 의미를 분리한다.

## 3. 전투 무대·캐릭터·연출

### 무대 배경

- **대1 혈랑채(P0):** 현재 960×540 이미지는 세로 전투창에 단순 확대·중앙 크롭하면 양쪽 전투자와 공격 궤적이 잘릴 수 있다. 목현 왼쪽·적 오른쪽, 공통 바닥선, 상단 적 체력 표시, 양쪽 공격 범위가 함께 보이는 **세로 전용 구성**을 제작한다. 가로 화면도 유지할 계획이면 같은 장소를 가로/세로 두 구도로 납품한다.
- **대2~10(P2):** 흑시장, 팽가, 사공 추종 구역, 혈교 살수 구역, 마두 근거지, 심마의 공간, 혈교 선봉 진지, 청운문, 혈교 하남지단의 배경 각 1장. 정확한 장소·시각 키워드는 [[스토리보드-기획서]]를 기준으로 콘셉트 승인 후 확정한다.
- **대11~20(P2):** 혈교 잔당 추적, 장강 수로채, 남궁세가, 화산파, 혈교 장로 거점, 천외 술법 공간, 타락한 전이자 구역, 정사대전, 혈교 총단 관문, 세계의 문/혈교주 결전의 배경 각 1장. [[스토리보드-기획서-챕터2]]를 기준으로 한다.
- **총량:** 대스테이지별 1구도 기준 20장이다. 지금은 대1 가로형 임시 배경만 있으므로 신규 고유 장면 19장과 대1 세로 구성 작업이 남는다. 시간대·날씨·보스용 변주는 별도 승인 전 필수 수량에 넣지 않는다.

배경에는 체력 바·버튼·문구를 그려 넣지 않는다. 세로 화면의 실제 전투창과 가로 960×540 화면을 각각 작게 축소해 실루엣, 바닥선, 텍스트 가독성, 캐릭터와 배경의 명도 분리를 검수한다. 한 장의 가로 그림을 기계적으로 자르는 방식으로 납품하지 않는다.

### 캐릭터와 초상

- **즉시 적용(P0):** 목현 1종과 혈랑채 적 4종의 기존 시트를 세로 무대에 배치한다. 주인공은 왼쪽에서 오른쪽을, 적은 오른쪽에서 왼쪽을 바라본다. 기존 적의 체형도 최신 2.5등신 SD 페인터리 기준에 맞는지 다시 확인하고 필요하면 수정 제작한다. 좌우 반전으로 방향을 맞추지 않는다.
- **전체 콘텐츠(P2):** `combat.ts`에는 대1~20 보스 20명, 대스테이지별 대표 잡몹 20종, 대1의 궁수·정예산적 변형 2종이 이름으로 정의되어 있다. 이를 모두 서로 다른 외형으로 만들면 **적 총 42종**이다. 현재 4종이 있으므로 **대2~20 대표 잡몹 19종+보스 19종=추가 38종**이 필요하다. 이 수량은 ‘각 이름을 고유 실루엣으로 보여 준다’는 제작 목표이며, 공유 외형을 허용하면 줄일 수 있다. 이름 데이터가 있는 것과 전용 이미지가 있는 것은 다르다.
- **모션 기준:** 현재 목현·대1 두목은 각 6모션, 나머지 대1 적은 각 5모션이다. 이 구성을 신규 38종에 그대로 적용하면 잡몹 19×5 + 보스 19×6 = **추가 209모션 시트**가 산술 예상치다. 모션 재사용/공통 연출 여부를 먼저 결정하면 제작량이 달라진다. 신규·재제작 시 [[캐릭터-이미지-생성-지침]]의 실제 투명 PNG, 약 2.5등신, 공통 프레임·여백·기준점·방향·6모션 최대 범위 검수를 적용한다.
- **초상·대화(P1/P2):** 내 정보의 목현 초상은 검수한 스프라이트에서 안전하게 크롭해 먼저 재사용한다. 보스 확인창·대화창도 전투 원화에서 얼굴 컷을 파생할 수 있는지 시험한 뒤, 읽히지 않는 인물만 초상 원화를 별도 제작한다. 동료/NPC 전신이나 컷신은 현재 시안의 필수 구성에 없으므로 스토리 화면 범위가 정해질 때 수량을 확정한다.

현재 일반·치명타 타격 효과와 숫자 이미지는 신규 제작 항목이 아니라 **모바일 배율 검수 항목**이다. 맞는 효과가 없는 피격·승리·패배·환골탈태 전환은 UI 애니메이션만으로 읽히는지 먼저 시험하고, 부족한 장면에만 전용 효과를 만든다. 번쩍임·흔들림은 움직임 감소 설정에서도 상태 문구로 결과를 확인할 수 있어야 한다.

## 4. 성장·장비·문파·상점

| 화면 | 제작할 그림·문양 | 합리적인 제작 단위 | 우선순위 |
|---|---|---|---|
| 무공 | 보드 표식, 초식 단계 문양, 연마/대성/잠금 표시 | 현재 보드 7개에 식별 표식 7종. 각 6노드=42개를 모두 별도 그림으로 만들 필요는 없고, 노드 단계·상태는 공통 도형과 텍스트로 표현 | P0/P1 |
| 장비 | 무기·몸통·머리·팔·발·허리·목·반지 슬롯 표식, 강화석·보호부적, 등급 프레임 | 데이터상 9슬롯이지만 반지 L/R은 같은 계열 그림을 공유하므로 슬롯 기본 그림 **8종**+좌우 위치 표기. 6등급은 색·테두리 규칙으로 구분하고, 개별 아이템마다 실루엣이 필요한지 데이터/상품 구성 확정 후 결정 | P0/P1 |
| 문파 | 청운문 문장·현판/배너, 기여도·문파 단계 표식 | 현 게임은 청운문 소속 고정이므로 우선 문장 **1종**. 기획상 가입 가능 문파 6곳의 나머지 문장은 실제 선택/등장 화면 범위가 정해지면 제작 | P0/P2 |
| 일반상점 | 영약 병 상품 그림, 교환 완료 표시 | 거래 상품은 현재 영약 1종이므로 상품 그림 **1종**. 화폐·보유량은 공통 재화 아이콘 재사용 | P0 |
| 기연 | 기연 뽑기 상징, 결과 카드 뒷면/등급 드러남, 장비 결과 썸네일 | 상징·공통 카드 각각 1종. 6등급 결과는 색/테두리/짧은 효과로 분기하고, 장비 썸네일은 장비 기본 그림을 재사용 | P1 |
| 환골탈태·보스 결과 | 환골탈태 문양, 전/후 비교, 보스 승리·보상 표식 | 공통 문양·결과 틀을 우선 설계. 단계별 다른 전신 그림·대형 컷신은 스토리 연출 범위 확정 후 제작 | P1/P2 |
| 첫 접속·이야기 | 인트로 3장, 도호 입력, 첫 연마 안내, 장면 대화, 보상·빈 상태 | 인트로는 [[모바일-UX-개선-기획서]]의 3장 흐름에 맞춘 **3개 장면 구성**을 계획한다. 기존 전투 배경·목현 컷 재사용 가능성을 먼저 확인하고 모자란 컷만 신규 원화로 제작한다. 나머지 안내는 공통 카드·강조선·아이콘을 사용 | P1/P2 |

장비 아이콘은 실제 인벤토리의 `slot + grade + itemLevel + enhanceLevel` 조합과 맞춰야 한다. 이름만 다른 동일 슬롯 장비에 임의의 유일 원화를 약속하지 않는다. 페이퍼돌 중앙의 목현은 별도 정지 그림보다 검수된 대기 모션/대표 프레임을 먼저 사용한다. 아이콘, 카드, 등급 테두리가 합쳐졌을 때 320px 화면에서도 장비 이름과 강화 수치가 읽혀야 한다.

## 5. 자산별 납품·검수 기준

| 유형 | 납품 기준 | 확인 항목 |
|---|---|---|

## 6. 제작 순서와 완료 판정

1. **P0 시안 실전화:** 디자인 토큰·5탭/재화/설정 아이콘, 대1 세로 무대, 기존 5캐릭터·효과의 모바일 실측, 무공 7보드 식별표식, 장비 8계열 기본 아이콘, 청운문 문장, 영약 상품 그림. 전투 화면에 독립 일시정지 버튼이 없고 설정창에서 정지·재개가 작동하는 화면을 기준으로 시각 검수한다.
2. **P1 전체 기능 품질:** 사냥터·보스 확인·결과·환골탈태·기연·첫 접속 3장·각종 빈 상태와 모달, 재료·상태 아이콘을 확정한다. 모든 5탭과 연결된 상세창에서 모양·표기·색의 의미가 같아야 한다.
3. **P2 콘텐츠 확장:** 대2~20 배경 19장과 신규 적 최대 38종을 스토리/전투 적용 순서로 제작한다. 단순히 파일만 쌓지 않고 각 스테이지에서 이름, 등장 그림, 모션, 배경이 맞는지 확인한다.

디자인 완성의 판정 기준은 파일 개수가 아니라 **실제 모바일 화면에서 캐릭터·배경이 잘리지 않고, 5탭과 설정/결과/성장 상태가 일관되며, 각 스테이지의 고유 이름과 그림이 일치하는 것**이다.
