# 무림인 키우기 — 장구(裝具) 시스템

## 서사

무협 세계관의 전통적 병기 등급 클리셰를 차용해 직관적으로 받아들이게 한다.

**등급 명칭 (하→상):**

1. **범병(凡兵)** — 저잣거리 대장간에서 흔히 찍어내는 병기.
2. **정련병(精鍊兵)** — 백 번 담금질(백련강)한 병기. 문파 하급 제자 지급 수준.
3. **영병(靈兵)** — 영기를 머금은 희귀 광석으로 벼려 내공을 흘려도 손상 없는 등급. 문파 하사품/전리품.
4. **보병(寶兵)/보물급(寶物級)** — 하나하나 이름을 가진 명기(名器).
5. **신병이기(神兵利器)** — 전설로만 전해지던 상고(上古)의 병기. 문파 보물창고나 기연(가챠) 전용 최상급.

**획득 서사 갈래:** 문파 하사품(퀘스트/레벨 보상) · 전리품(보스전 드롭) · 대장장이 제작(재화 소모 상점 구매/강화) · 기연 획득(가챠).

## UX

무공 탭과 동일하게 중앙 캔버스 위 1400x900 모달(반투명 딤, 상단 "대련 진행 중" 인디케이터 유지)로 진입. 좌(파퍼돌) / 우(슬롯 상세 + 인벤토리) 2분할.

**슬롯 구성 (8슬롯):** 무기(병기) · 몸통(갑주) · 머리(두건) · 팔(완갑) · 발(경신화) · 허리(요대) · 목(패도목걸이) · 손가락 L/R(지환).

**슬롯 상세 카드:** 아이콘(등급색 테두리) · 등급명 · 스탯 · 강화 단계(+N, "대성까지 M단계" 서브텍스트) · 성공확률 게이지(초록70%+/황색40~70%/빨강40%미만) · 강화 비용 · 강화 버튼(무공 탭 "연마하기"와 동일 컨벤션) · 보호부적 체크박스(+15 이상 구간).

**인벤토리:** 6열 그리드, 등급색 테두리 + 좌하단 강화단계 배지. 필터(전체/무기/방어구/장신구), 정렬(등급순/강화단계순/최신순). 클릭 시 장착 미리보기(현재 장착과 스탯 비교, 상승 ▲초록/하락 ▼빨강) 후 [장착]. 다중선택 [일괄 분해] → 강화석 환급.

## 수치

**슬롯 구성 및 스탯 비중 (6슬롯 단순화 기준):**

| 슬롯 | 주 스탯 비중 |
|---|---|
| 무기 | ATK 70% / 치명타율 20% / 치명타피해 10% |
| 갑주(상체) | DEF 50% / HP 40% / 상태이상 저항 10% |
| 하의 | HP 60% / DEF 30% / 회피율 10% |
| 신발 | 회피율 40% / 공격속도 40% / DEF 20% |
| 목걸이 | 내공 획득량 30% / ATK 40% / 치명타피해 30% |
| 반지 | 치명타율 50% / 치명타피해 30% / ATK 20% |

`BaseStat = ItemLevel × Coeff × SlotWeight × GradeMultiplier`

**등급별 배율:**

| 등급 | 배율 | 획득처 |
|---|---:|---|
| 하품 | ×1.0 | 일반 스테이지 드랍 |
| 중품 | ×1.5 | 소보스(X-5) 이상 |
| 상품 | ×2.3 | 대보스(X-10) / 상점 |
| 보물급 | ×3.5 | 기연 전용 / 최종보스 확률 드랍 |

**강화 성공 확률 (+0~+15):**

| 강화 단계 | 성공 확률 | 실패 페널티 |
|---|---:|---|
| +1 ~ +5 | 100% | 없음 |
| +6 ~ +10 | 90%→70% (5%p씩 감소) | 없음(비용만 소모) |
| +11 ~ +15 | 50%→30% (5%p씩 감소) | 30% 확률로 단계 -1 하락, 보호부적으로 방지 가능 |

**강화 비용 곡선:** `EnhanceCost(level) = BaseCost × 1.6^level` [내공, +11 이상은 내공+영약 병행]. BaseCost=100 기준 → +5: 1,049 / +10: 10,737 / +15: 109,951 내공.
