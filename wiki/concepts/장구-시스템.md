# 무림인 키우기 — 장구(裝具) 시스템

> **등급 체계 통합 (2026-07-27):** 장구/기연 아이템 등급은 프로젝트 전체에서 아래 6단계 하나로 통일한다. 이전 버전에 있던 서사 5단계(범병/정련병/영병/보병/신병이기), UX 6단계 색상표, 수치 4단계(하품/중품/상품/보물급), 상점-기연 가챠 4단계(일반/희귀/영웅/전설)는 전부 이 표로 대체한다. 자세한 배율/확률은 [[상점-기연-시스템]] 참고.

## 등급 체계 (전 시스템 공통 기준)

| 등급명(수치) | 서사 명칭 | 색상 | 배율 |
|---|---|---|---:|
| 하품 | 범병(凡兵) | 회색 `#9e9e9e` | ×1.0 |
| 중품 | 정련병(精鍊兵) | 초록 `#4caf50` | ×1.3 |

## 서사

무협 세계관의 전통적 병기 등급 클리셰를 차용해 직관적으로 받아들이게 한다. 하품(범병)은 저잣거리 대장간에서 흔히 찍어내는 병기, 중품(정련병)은 백 번 담금질(백련강)한 문파 하급 제자 지급 수준, 상품(영병)은 영기를 머금은 희귀 광석으로 벼려 내공을 흘려도 손상 없는 등급(문파 하사품/전리품), 절품(보병)은 하나하나 이름을 가진 명기(名器), 신품(신병)은 극소수 장인만 벼릴 수 있는 신기(神器)에 근접한 물건, 선품(신병이기)은 전설로만 전해지던 상고(上古)의 병기(문파 보물창고나 기연 전용 최상급).

**획득 서사 갈래:** 문파 하사품(퀘스트/레벨 보상) · 전리품(보스전 드롭) · 대장장이 제작(재화 소모 상점 구매/강화) · 기연 획득(가챠).

## UX

무공 탭과 동일하게 중앙 캔버스 위 1400x900 모달(반투명 딤, 상단 "대련 진행 중" 인디케이터 유지)로 진입. 좌(파퍼돌) / 우(슬롯 상세 + 인벤토리) 2분할.

```
┌───────────────────────┬────────────────────────────────────────┐
│     ┌───────┐         │  [선택 슬롯 상세 카드]                   │
│     │ 두건  │         │  🗡 무형검(無形劍)      [절품]           │
│  목걸이┤캐릭터│완갑    │  공격력 +320 / 치명타 +8%                │
│     │실루엣 │         │  강화 단계: +12                          │
│     ├───────┤         │  강화 성공확률: 74%                      │
│  지환L┤ 갑주  │지환R   │  강화 비용: 전(錢) 8,400 + 강화석 x3      │
│     ├───────┤         │  [강화하기]        [보호부적 사용□]      │
│  허리띠┤ 신발  │       │  ─────────────────────────────────────  │
│     └───────┘         │  인벤토리(필터: 전체|무기|방어구|장신구)  │
│  (8슬롯 파퍼돌)        │  [▦][▦][▦][▦][▦][▦]  등급색 테두리 그리드│
└───────────────────────┴────────────────────────────────────────┘
```

**슬롯 구성 (9슬롯, 2026-07-27 수치 정정 — 이전 버전엔 "8슬롯"으로 잘못 표기됐었음):** 무기(병기) · 몸통(갑주) · 머리(두건) · 팔(완갑) · 발(경신화) · 허리(요대) · 목(패도목걸이) · 손가락 L(지환) · 손가락 R(지환) = 9개.

**슬롯 상세 카드:** 아이콘(등급색 테두리) · 등급명 · 스탯 · 강화 단계(+N, "대성까지 M단계" 서브텍스트) · 성공확률 게이지(초록70%+/황색40~70%/빨강40%미만) · 강화 비용(전(錢)) · 강화 버튼(무공 탭 "연마하기"와 동일 컨벤션) · 보호부적 체크박스(+15 이상 구간).

**인벤토리:** 6열 그리드, 등급색 테두리 + 좌하단 강화단계 배지. 필터(전체/무기/방어구/장신구), 정렬(등급순/강화단계순/최신순). 클릭 시 장착 미리보기(현재 장착과 스탯 비교, 상승 ▲초록/하락 ▼빨강) 후 [장착]. 다중선택 [일괄 분해] → 강화석 환급.

## 수치

**슬롯 구성 및 스탯 비중 (9슬롯 정본, 2026-07-27 수정 — 이전 "6슬롯 단순화" 표는 실제 슬롯 수와 안 맞아 폐기):**

| 슬롯 | 주 스탯 비중 |
|---|---|
| 무기(병기) | ATK 70% / 치명타율 20% / 치명타피해 10% |
| 몸통(갑주) | DEF 50% / HP 40% / 상태이상 저항 10% |
| 머리(두건) | HP 40% / DEF 30% / 치명타피해 30% |
| 팔(완갑) | ATK 30% / 공격속도 40% / 치명타율 30% |
| 발(경신화) | 회피율 40% / 공격속도 40% / DEF 20% |
| 허리(요대) | HP 50% / DEF 50% |
| 목(패도목걸이) | 내공 획득량 30% / ATK 40% / 치명타피해 30% |
| 손가락 L(지환) | 치명타율 50% / ATK 30% / 치명타피해 20% |
| 손가락 R(지환) | 치명타율 30% / 치명타피해 50% / ATK 20% |

`BaseStat_슬롯 = ItemLevel × Coeff × SlotWeight × GradeMultiplier` — GradeMultiplier는 위 등급 체계 표의 배율(×1.0~×4.0). ItemLevel은 드랍 시점의 대략 캐릭터 레벨과 동일하게 취급(`ItemLevel ≈ 캐릭터Lv`), Coeff=20(예시 상수), SlotWeight는 위 표의 각 스탯 비중(%)을 0~1로 환산한 값. `BaseStat_gear_총합 = Σ(9슬롯의 BaseStat_슬롯)` — [[스테이지-레벨링-기획서]] 7장 전투력 공식의 `BaseStat_총합` 항 중 장구 기여분이다.

**등급별 획득처:**

| 등급 | 획득처 |
|---|---|
| 하품 | 일반 스테이지 드랍 |
| 중품 | 소보스(X-5) 이상 드랍 |
| 상품 | 대보스(X-10) 드랍 / 상점 구매 |
| 절품 | 대보스(X-10) 확정 드랍(대스테이지 전용 1종) / 기연 |
| 신품 | 기연 전용 (일반 등급, [[상점-기연-시스템]] 참고) |
| 선품 | 기연 전용 (천장/최상급 등급) |

**강화 성공 확률 (+0~+15):**

| 강화 단계 | 성공 확률 | 실패 페널티 |
|---|---:|---|
| +1 ~ +5 | 100% | 없음 |
| +6 ~ +10 | 90%→70% (5%p씩 감소) | 없음(비용만 소모) |
| +11 ~ +15 | 50%→30% (5%p씩 감소) | 30% 확률로 단계 -1 하락, 보호부적으로 방지 가능 |

**강화 재화 (통일):** 장구 강화는 전(錢) 하나로 통일한다 — 내공(무공/문파무공 전용)과는 별개 재화다. `EnhanceCost(level) = BaseCost × 1.6^level` [전(錢), +11 이상은 전+영약 소량 병행]. BaseCost=100 기준 → +5: 1,049 / +10: 10,737 / +15: 109,951 전. 전(錢) 획득처는 [[스테이지-레벨링-기획서]]의 `Gold(N,S)` 곡선(소스테이지 클리어 보상)과 동일 — 즉 스테이지 문서의 "Gold"는 곧 이 "전(錢)"이다.

**강화석:** +6 이상 구간부터 필요, 강화 단계당 `StoneCost(level) = ceil(level / 3)` 개(예: +6~+8: 2개, +9~+11: 3개). 획득처: 일반 스테이지 확률 드랍(등급별 획득처 표의 하품/중품 스테이지에서 동반 드랍) 및 인벤토리 [일괄 분해] 환급.

**강화 단계의 스탯 효과 및 이중계산 방지 규정 (2026-07-27 신규 정의):** 강화(+N)는 `ItemLevel`을 올리지 **않는다** — 순수하게 [[스테이지-레벨링-기획서]] 7장 전투력 공식의 `Σ가산버프` 쪽 "장구 강화 단계 보너스(%)" 항으로만 반영한다. 이렇게 분리해야 같은 강화가 BaseStat_gear(등급/드랍 시점 고정)와 가산버프 양쪽에서 중복 계산되지 않는다.

`장구강화버프(%) = Σ(9슬롯의 강화단계) × 1.5%`

예시: 9슬롯 전부 +20(대성) 도달 시 = 9×20×1.5% = 270%. 실제 플레이에서는 슬롯마다 강화 진행도가 다르므로 현재 보유 강화단계 합계를 그대로 대입.
