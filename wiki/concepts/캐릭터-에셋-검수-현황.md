# 캐릭터 에셋 검수 현황

[[캐릭터-이미지-생성-지침]]의 실행용 체크 목록이다. 아래 공통 체크리스트는 앞으로 생성하는 주인공·적 모든 캐릭터에 적용한다. 생성 후보, 패킹된 런타임 에셋, 게임 적용 검수를 구분한다.

## 1. 이미지 생성 후 공통 검토 체크리스트

새 원화나 모션 프레임을 생성한 직후에는 아래 순서대로 검토한다. 하나라도 통과하지 못하면 해당 결과는 후보로만 보관하고, 런타임 시트에 넣지 않는다.

| 단계 | 반드시 확인할 사항 | 통과 기준 |
|---|---|---|
| 기준 대조 | 승인된 대기 이미지와 약 2.5등신 SD 비율, 의상·무기·색, 응시 방향, 모션 순서 | 주인공은 오른쪽 응시·왼쪽 루트, 적은 왼쪽 응시·오른쪽 루트. 모든 모션의 외형 기준이 하나다. |
| 원화 품질 | 전신·발·무기·공격 궤적의 완전한 표시, 포즈별 신체 배율, 프레임 간 손과 무기 연결 | 잘린 사지·이웃 포즈 조각·프레임별 자동 확대가 없다. 공격은 준비→정점→회복, 사망은 무기와 자세가 연속된다. |
| 프레임 고유성 | 프레임별 역할, 몸통·관절·무기 끝점·무게 중심·옷자락 변화, 인접 프레임 중복 | 접속용 시작·종료 외의 모든 프레임이 다른 동작이다. 인접 프레임은 최소 두 동작 요소가 다르고 실제 게임 배율에서도 구분된다. |
| 투명화 | 실제 RGBA 알파, 체크 무늬·흰색·검은색 배경 픽셀, 가장자리 잔상, 흰 의상·칼날 손실 | 투명 영역의 알파가 0이며, 어두운색·밝은색·유채색 합성에서 배경 잔상·구멍·테두리가 없다. |
| 패킹 | 공통 셀 크기, 루트/지면 기준, 32px 안전 여백, JSON의 프레임·duration·anchor | 한 캐릭터의 모든 모션이 같은 셀·루트를 쓰며, 공격 범위와 쓰러짐도 셀 안에 완전히 들어간다. |
| GIF 검수 | 정상 속도·2배 저속의 대기 루프, 공격·사망 연결, 발과 몸통의 순간 이동 | 정지하거나 같은 포즈가 두 번 재생되는 구간이 없고 발 기준선·신체 배율·무기 길이가 튀지 않는다. 사망 마지막 프레임은 홀드한다. |
| 게임 적용 | 실제 로더의 앵커, 화면 표시 배율, 무대 바닥선, 상태 전환, 모바일 안전 영역 | 전투 화면에서 잘림·겹침·로딩 실패가 없고, 대기·공격·사망 전환이 의도한 위치에서 재생된다. |

### 결과 분류

- **생성 후보:** 원화 품질 또는 투명화 검토 전 결과. 원본 파일은 보관하지만 게임에는 연결하지 않는다.
- **패킹 검수 통과:** 실제 알파·공통 셀·루트·여백·GIF 연결을 통과한 PNG와 JSON. 게임 적용 전까지는 후보 런타임 에셋이다.
- **게임 적용 검수 통과:** 로더·상태 전환·모바일 화면 검수까지 통과한 에셋. 해당 캐릭터의 런타임 에셋으로 사용한다.

## 2. 목현 v2 완료 현황

| 항목 | 상태 | 근거 |
|---|---|---|
| 외형 기준 | 완료 | `wiki/raw/assets/mokhyeon-idle-v2-candidate.png`를 기준으로 청록·아이보리 무복, 흑발 상투와 청록 끈, 은색 직검을 유지했다. |
| 네 상태 프레임 | 완료 | 대기·공격1·공격2·사망의 프레임 수는 6·9·9·8이다. 공격·사망의 추가 프레임은 기존 원화의 작은 루트 고정 변형으로 제작했다. 원본 후보와 GIF는 `wiki/raw/assets/`에 보관한다. |
| 투명 PNG | 완료 | 런타임 시트 4종은 RGBA PNG다. 공격2 타격 후보에서 발견한 체크 무늬 픽셀은 교체했다. |
| 공통 셀·기준점 | 완료 | 모든 시트는 4열·1024×1024px 셀이다. 9프레임 공격 시트는 4096×3072px, 나머지는 4096×2048px다. 루트는 `(300, 896)`, 최소 안전 여백은 32px이다. |
| 모션 파일 검수 | 보완 필요 | GIF와 파일 해시 기준으로 공격 시트의 9프레임은 서로 다르다. 다만 2·4·8번은 기존 키포즈의 루트 고정 변형이므로, 새 규칙에 따라 관절·무기 위치까지 다른 고유 중간 자세인지 실제 게임 배율에서 다시 판정한다. |
| 런타임 연결 | 완료 | `BattleCanvas`가 `mokhyeon-v2` 시트를 읽고, `sprite.ts`가 JSON의 `anchor`를 사용한다. 목현 표시 배율은 0.45로 조정했다. |
| 코드·배포 빌드 | 완료 | ESLint·TypeScript·Vite 빌드를 통과했고 새 PNG·JSON이 배포 파일에 포함됐다. |
