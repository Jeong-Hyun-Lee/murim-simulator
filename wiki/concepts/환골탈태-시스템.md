# 무림인 키우기 — 환골탈태(換骨奪胎) 시스템

> **2026-07-27 수정:** 1회차 리셋 게이트를 대스테이지 5에서 **대스테이지 7**로 이동해 [[스토리보드-기획서]] 7장(소주천 완성·심마 대면)과 시점을 일치시켰다. 경지명 체계도 서사(후천~등봉조극)로 통일하고, UX 목업의 "삼류 무사→이류 무사" 예시는 자리표시자였음을 명시한다. 아래 본문에 반영 완료.

## 서사

환골탈태는 본래 도가 내단술에서 "낡은 뼈와 몸을 벗고 완전히 새로운 몸으로 다시 태어난다"는 뜻으로, 득도한 자가 인간의 한계를 넘어서기 직전 겪는 관문이다. 이를 리셋 시스템에 대입하면:

> 내공은 그릇(단전)에 담기는 법. 그릇의 크기를 넘어서는 내공을 억지로 쌓으면 주화입마에 빠진다. 진정한 고수는 어느 경지에 이르면 낡은 그릇 자체를 깨고 — 뼈를 바꾸고 골수를 갈아 — 더 큰 그릇으로 다시 빚어낸다. 그 과정에서 지금까지 쌓았던 내공은 흩어지지만, 몸이 완전히 새로 태어난 만큼 이후 수련은 이전과 비교할 수 없이 빨라진다.

즉 "처음부터 다시 수련"이 아니라 **"더 높은 곳으로 가기 위해 일부러 밑바닥으로 돌아가는 선택"**으로 프레이밍한다.

**4회차 이후 반복(대10 재도전) 서사적 정당화 (2026-07-27 추가):** 척망은 6장 엔딩에서 이미 소멸했으므로, 4회차 이후 반복은 "척망을 다시 죽이는" 것이 아니라 **"환골탈태 때마다 가장 큰 고비였던 그 대련의 기억을 되짚어 스스로와 다시 겨루며 경지를 다지는 수련"**으로 설명한다 — 무협 클리셰의 "관문을 마음속에서 재현해 극복하는 심상 수련" 개념. UI상으로도 보스 조우 다이얼로그 문구를 반복 도전 시 "회상 대련: 혈교 하남지단주 척망"처럼 표기해 실제 재대결이 아님을 암시한다.

**경지명 승급 체계 (유일 채택안):** 후천(後天, 초기값/0회) → 선천(先天, 1회) → 초절정(超絕頂, 2회) → 화경(化境, 3회) → 현경(玄境, 4회) → 생사경(生死境, 5회) → 등봉조극(登峰造極, 6회 이상, 이후 "등봉조극 N중"으로 회차만 누적 표기). 환골탈태 1회차마다 경지가 하나씩 오르고 호칭도 변화(예: "청운문의 애송이" → "청운문 후기지수" → "일방(一方)의 고수" → "강호에 이름을 알린 대협(大俠)"). UX 목업(`ux-시나리오-목업.html`)의 "삼류 무사→이류 무사"는 초기 예시 텍스트였을 뿐 정식 채택안이 아니며, 실제 표시는 이 경지명 체계를 사용한다.

## UX

**진입 게이트 (조건 미충족 시):** 무공 탭과 동일한 잠김 컨벤션(자물쇠 오버레이 + 회색 처리 + "6대 스테이지 클리어 필요" 텍스트 + 현재 진행도).

**리셋 비교 화면 (핵심):** "잃는 것"과 "영구히 얻는 것"을 좌/우 대비로 분리.

```
┌──────────────────────────────────────────────────────────────────┐
│  환골탈태(換骨奪胎) — 3회째 도전          현재 경지: 삼류 무사      │
├───────────────────────────┬────────────────────────────────────┤
│   ⚠ 잃는 것 (붉은 테두리)   │   ✦ 영구히 얻는 것 (금색 테두리)      │
│  · 스테이지 진행(4-7→1-1)   │  · 환골탈태 포인트 +85               │
│  · 무공 보드 레벨 전체 초기화│  · 전체 스탯 영구 배율 +15%(누적)    │
│  · 보유 내공/전 전액 소각    │  · 신규 칭호 "환골 3회 · 절정고수"   │
│  · (영약/장구/문파는 유지)   │  · 다음 회차 내공 획득량 +10%        │
├───────────────────────────┴────────────────────────────────────┤
│              [취소]                    [환골탈태 진행하기]        │
└──────────────────────────────────────────────────────────────────┘
```

유지되는 항목도 "잃는 것" 칸 하단에 회색 텍스트로 명시해 오해 방지. [환골탈태 진행하기]는 되돌릴 수 없는 조작이므로 1차 클릭 후 2차 확인 다이얼로그("정말로 진행하시겠습니까? 되돌릴 수 없습니다")로 재확인.

**리셋 후 결과 연출:** 화이트아웃(0.5초) → 금빛 파티클 → 중앙 대형 승급 배너("삼류 무사 → 이류 무사", 슬라이드+확대) → 획득 내역 요약 카드 → [계속하기](자동 진행 금지, 보스 격파 팝업과 동일하게 사용자 확인 필요) → 닫으면 1-1 복귀, 좌측 패널 스탯이 새 배율로 카운트업.

**환골탈태 횟수 카운터 표시 위치 (2026-07-27 수정):** 경지명 자체가 환골탈태 회차와 1:1 대응([[ux-시나리오-기획서]] 5-3절, "선천"=1회 등)이므로 좌측 패널에 별도 배지는 불필요 — 경지명 표기("{경지명} · {N}성")가 곧 카운터 역할을 겸한다. 회차 숫자를 명시적으로 보여줘야 하는 곳(환골탈태 탭 헤더의 "N회째 도전", 문파 화면 문파원 목록의 랭킹 표기 등)에서만 별도로 회차 숫자를 병기한다.

## 수치

**리셋 조건 (반복 가능, 게이트 점증):**

| 환골탈태 회차 | 조건 |
|---|---|
| 1회차 | 대스테이지 7 보스(심마) 클리어 — [[스토리보드-기획서]] 7장 "소주천 완성"과 시점 일치 |
| 2회차 | 대스테이지 9 보스 클리어 |
| 3회차 | 대스테이지 10 보스(척망) 클리어 |
| 4회차 이후 | 대스테이지 10 보스 클리어(반복 파밍 게이트 고정) |

(기존 "1회차=대5 AND 삼재검법 대성" 조건은 폐기 — 삼재검법 1보는 통상 대5 이전에 자연히 대성되므로 별도 조건으로서 의미가 약했고, 무엇보다 대5 시점엔 스토리상 대응하는 각성 이벤트가 없었다.)

**초기화 vs 유지:**

| 초기화(잃음) | 유지 |
|---|---|
| 캐릭터 레벨 → 1 | 영약 보유량 |
| 스테이지 진행도 → 1-1 | 문파 기여도·문파무공 진행도 |
| 무공 노드 레벨(전부 0, 해금된 보드 자체는 유지) | 장비(강화 단계 포함) |
| 소지 내공 | 도감/컬렉션, 누적 환골탈태 횟수, 영구 버프 |
| | 신규 재화 "환단"(회당 1~3개, 프레스티지 전용 상점용 확장 여지) |

**영구 버프 공식:** `전체 스탯 배율 = 1 + 0.15 × N` (N = 누적 환골탈태 횟수). 1회차 +15%, 3회차 +45%, 5회차 +75%, 10회차 +150%. (runaway 방지 필요 시 `1 + 0.15×N^0.9` 같은 체감형 대안 고려)

**재도전 클리어 속도 예시 (대1~2 기준):**

| 누적 환골탈태 | 영구버프 | 클리어 소요(예시) |
|---|---:|---:|
| 0회 | +0% | ≈ 30분 |
| 1회 | +15% | ≈ 22분 |
| 3회 | +45% | ≈ 12분 |
| 5회 | +75% | ≈ 7분 |
| 10회 | +150% | ≈ 3분 |

장비 유지 효과까지 겹치면 실제 체감 단축폭은 더 큼 — 초반 재도전 구간은 빠르게 통과하는 워밍업으로 기능.
