# 무림인 키우기 — 환골탈태(換骨奪胎) 시스템

스토리 이정표 보스를 넘을 때마다 한 번씩 경지를 돌파해 전체 능력치를 영구히 올리는 시스템. 잃는 것은 없다 — 레벨·내공·무공·스테이지는 그대로 이어진다.

## 서사

환골탈태는 본래 도가 내단술에서 "낡은 뼈와 몸을 벗고 완전히 새로운 몸으로 다시 태어난다"는 뜻으로, 득도한 자가 인간의 한계를 넘어서기 직전 겪는 관문이다.

> 내공은 그릇(단전)에 담기는 법. 그릇의 크기를 넘어서는 내공을 억지로 쌓으면 주화입마에 빠진다. 진정한 고수는 큰 고비를 넘긴 순간, 쌓아 온 내공을 흩지 않은 채 뼈를 바꾸고 골수를 갈아 그릇 자체를 넓힌다. 몸이 새로 태어난 만큼 같은 내공으로도 이전과 비교할 수 없는 힘이 나온다.

고비 하나에 돌파 한 번이다. 게이트가 되는 보스는 모두 이야기의 전환점(심마 대면, 척망 결전, 천외의 등장 등)이고, 그 싸움을 넘긴 깨달음이 돌파의 계기가 된다.

**경지명 승급 체계:** 후천(後天, 0회) → 선천(先天, 1회) → 초절정(超絕頂, 2회) → 화경(化境, 3회) → 현경(玄境, 4회) → 생사경(生死境, 5회) → 등봉조극(登峰造極, 6회 이상, "등봉조극 N중"으로 표기). 환골탈태 1회마다 경지가 하나씩 오르고 호칭도 변화(예: "청운문의 애송이" → "청운문 후기지수" → "일방(一方)의 고수" → "강호에 이름을 알린 대협(大俠)").

환골탈태 횟수는 누적 수련 목표(1·3·5·7회)로도 보상된다([[장기-플레이-시스템]]).

## UX

**진입:** 대7 클리어부터 환골탈태 화면이 열린다. 게이트를 넘어 실행할 수 있게 되면 전투 화면에 "환골탈태 가능" 알림이 뜬다.

**환골탈태 화면:**

```
┌────────────────────────────────────┐
│  현재 경지   화경      3회 · 영구 +45% │
│                 ↓                  │
│  다음 경지   현경          영구 +60% │
│  대15 보스 클리어 필요 · 현재 대12     │
├────────────────────────────────────┤
│          [환골탈태 진행]             │
└────────────────────────────────────┘
```

- 조건을 채우면 버튼이 켜지고, 누르면 확인 창 없이 바로 실행한다(잃는 것이 없으므로).
- 실행 뒤 결과 카드("○○ 경지에 올랐습니다. 영구 능력치 +N%")를 보여주고, [확인]을 누르면 같은 화면으로 돌아와 다음 경지를 보여준다.
- 여러 게이트를 이미 넘은 상태면 이어서 연속으로 실행할 수 있다.
- 마지막 게이트까지 돌파하면 "모든 경지를 돌파했습니다"만 표시하고 버튼을 숨긴다.

**횟수 표시:** 경지명이 환골탈태 회차와 1:1로 대응하므로 상단 초상 옆 경지명이 곧 카운터다. 회차 숫자는 환골탈태 화면과 내 정보에서만 병기한다.

## 수치

**게이트 (회차마다 1회):**

| 환골탈태 회차 | 조건 |
|---|---|
| 1회차 | 대스테이지 7 보스(심마) 클리어 — [[스토리보드-기획서]] 7장 "소주천 완성"과 시점 일치 |
| 2회차 | 대스테이지 9 보스 클리어 |
| 3회차 | 대스테이지 10 보스(척망) 클리어 — 챕터1 완결 |
| 4회차 | 대스테이지 15 보스(혈교 이장로) 클리어 — [[스토리보드-기획서-챕터2]] 15장 "천외(天外) 첫 언급"과 시점 일치 |
| 5회차 | 대스테이지 20 보스(혈교주) 클리어 — 챕터2 완결 |
| 6회차 | 대스테이지 25 보스(천외 탐혼사) 클리어 — [[스토리보드-기획서-챕터3]] 25장 "천외 삼사 첫 등장"과 시점 일치 |
| 7회차 | 대스테이지 30 보스(천외주) 클리어 — 챕터3 완결 |
| 8회차 | 대스테이지 35 보스(귀허 술사 백연) 클리어 — [[스토리보드-기획서-챕터4]] 35장 "두 번째 문 발견"과 시점 일치 (챕터4 기획) |
| 9회차 | 대스테이지 40 보스(종리헌) 클리어 — 챕터4 완결 (챕터4 기획) |

현재 코드는 대30까지이므로 7회가 상한이다(`rebirthData.ts`). 게이트는 "스토리 이정표에 건다"는 원칙으로 고른다 — 챕터 중반 전환점과 챕터 완결에 하나씩. 새 챕터가 들어오면 같은 원칙으로 게이트를 추가한다.

**실행 시 변화:**

| 바뀌는 것 | 그대로인 것 |
|---|---|
| 환골탈태 횟수 +1 (경지명 승급) | 캐릭터 레벨·경험치 |
| 전체 스탯 영구 버프 | 보유 내공·전·영약·강화석 |
| | 무공 노드 레벨 |
| | 스테이지 진행·사냥터 상태·수련탑 진행 |
| | 장비, 문파, 기연 천장, 수련 목표 기록 |

**영구 버프 공식:** `환골탈태 버프(%) = 15 × N` (N = 누적 환골탈태 횟수). 무공·문파 특전과 같은 가산 버킷에 더해 기본 스탯 총합에 한 번 곱한다([[스테이지-레벨링-기획서]] 7장). 1회 +15%, 3회 +45%, 7회 +105%.

**진행 곡선과의 관계:** 다시 오르는 구간이 없어 버프가 곧바로 최전선 돌파력이 된다. 챕터3 길이를 지키기 위해 대21 이후 몬스터 성장률을 올려 두었다([[스테이지-레벨링-기획서]] 13절). 시뮬레이션상 대10 클리어 시점 2~3회, 대20 시점 4~5회, 대30 클리어 직후 7회다.
