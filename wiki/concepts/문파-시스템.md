# 무림인 키우기 — 문파(門派) 시스템

## 서사

목현의 본산은 청운문이지만, 무림에는 여러 대문파가 병존하며 각기 다른 무학 철학을 갖는다.

| 문파 | 성격/특전 | 서사적 이유 |
|---|---|---|
| **청운문** (주인공 소속) | 균형형, 삼재검법 계열 | 정파의 표준 교본을 가르치는 중견 문파. "기본에 충실하라"는 가르침이 목현의 융합적 재능을 가리지 않는 토양이 됨. |
| **화산파** | 속도/쾌검 특화 | 험준한 화산 절벽에서 단련한 신법에서 비롯된 쾌검 전통. "느린 검은 죽은 검이다." |
| **무당파** | 심법/방어·내구 특화 | 도가 수련의 본산. 싸움보다 양생(養生)과 조화를 우선시. |
| **남궁세가** | 패도/공격력 특화 | 대대로 검룡을 배출해온 무가. 정면 승부를 마다하지 않는 패도적 가풍. |
| **개방** | 정보/기동성 특화 | 화려한 무공보다 발 빠른 정보력과 신법, 실전 생존 잡기. |
| **소림사** | 외공/생존력 특화 | 불문 무학 총본산. 참선과 외공 단련으로 몸 자체를 병기로 만듦. |

가입 시 문파 특전(예: 무당파=태극권 해금)은 "그 문파의 심법을 전수받아야만 익힐 수 있는 무공"이라는 논리로 잠금 해제와 자연스럽게 맞물린다. 목현이 청운문 소속이면서 타 문파에 객원 제자로 입문하거나 교류전으로 무공을 배운다는 설정이 다문파 조합 시스템의 명분이 된다.

## UX

**미가입 — 문파 목록/가입 화면:**

```
┌──────────────────────────────────────────────────────────────────┐
│  문파(門派)                    [검색]  정렬: 활동순▾               │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐               │
│  │ 🏯 화산파      │ │ 🏯 종남파      │ │ 🏯 청명문     │  카드 반복    │
│  │ Lv18 · 42/50  │ │ Lv12 · 30/50  │ │ Lv5 · 8/50   │               │
│  │ "매일 접속!"   │ │ "초보 환영"    │ │ 모집중        │               │
│  │ [가입 신청]    │ │ [가입 신청]    │ │ [가입 신청]    │               │
│  └──────────────┘ └──────────────┘ └──────────────┘               │
└──────────────────────────────────────────────────────────────────┘
```

카드 = 엠블럼 + 문파명 + 레벨 + 인원(현재/정원) + 한줄 소개 + [가입 신청]. 버튼 상태: 활성(가입가능) / 비활성("이미 소속" 회색) / 잠김("계정 Lv10 필요") / 만석(회색).

**청운문 예외 (2026-07-27 추가):** 목현은 스토리상 시작부터 청운문 소속이므로, 청운문 카드는 목록에서 "가입 신청" 버튼 대신 처음부터 "내 문파" 라벨(활성/강조 스타일)로 표시되고 클릭 시 바로 아래 2-2 문파 홈 화면으로 진입한다. 다른 5개 문파(화산파/무당파/남궁세가/개방/소림사)만 실제 "가입 신청" 대상이며, 청운문 소속 상태에서 타 문파로 이적 가능 여부는 범위 밖(추후 검토).

**가입 후 — 문파 홈:**

```
┌──────────────────────────────────────────────────────────────────┐
│  🏯 화산파   Lv18  ▓▓▓▓▓▓▓░░░ (문파 경험치 72%)                    │
├───────────────────────┬────────────────────────────────────────┤
│  문파원 목록 (42/50)   │  나의 기여도: 오늘 320/500 ▓▓▓▓▓▓▓░░░       │
│  장문인/장로/제자 순    │  누적 기여도 12,400  [기여하기(내공 헌납)] │
│  온라인 점, 기여랭킹배지│  ─────────────────────────────────────  │
│                       │  문파 특전(레벨 달성 시 자동 적용)         │
│                       │  ▸ Lv10: 공격력 +3%(활성) ▸ Lv20: 치명타+2%(잠김,90%)│
│                       │  ─────────────────────────────────────  │
│                       │  문파 무공: 화산검법 [보드 미리보기]       │
└───────────────────────┴────────────────────────────────────────┘
```

문파 특전은 무공 탭 노드 카드 축소판 리스트, 상태 규칙(활성/잠김+진행률%) 동일 재사용. 문파 전용 보드는 이 화면엔 미리보기 카드만, 실제 노드 그래프는 "무공" 탭에서 동일 템플릿으로 열람 — 미해금 시 잠김("문파 Lv15 필요"), 해금 후 "무공 탭에서 열기" 링크. [탈퇴]는 오조작 방지 위해 별도 설정 서브메뉴에 격리.

## 수치

**기여도 획득:**

| 획득처 | 기여도 | 주기 |
|---|---:|---|
| 일일 문파 임무 3종 | 각 30~50 | 일 1회 |
| 문파 토벌전(주간 보스) | 300 | 주 1회 |
| 내공 기부 | 1,000 내공 = 1 기여도(체감 감소) | 상시 |
| 영약 기부 | 영약 1개 = 10 기여도 | 상시 |

일 평균 기대치 ≈ 150~250 기여도/일(기부 제외).

**기여도 소모처:** 문파상점(강화석/재련재료/소량 영약, 100~2,000 기여도 단가), 문파무공 해금/강화.

**문파무공(태극권 등) 해금 총량:** 무공 보드와 동일 트리(기수식→1차×3→2차×2→캡스톤)를 기여도로 강화. `Cost(n) = BaseCost × 1.13^(n-1)` [기여도]

| 노드 | BaseCost | 최대Lv | 개당 합계 |
|---|---:|---:|---:|
| 1차 ×3 | 20 | 30 | ≈ 1,000 → 3,000 |
| 2차 ×2 | 100 | 30 | ≈ 4,800 → 9,600 |
| 캡스톤 | 800 | 10 | ≈ 2,500 |
| **합계** | | | **≈ 15,100 기여도** |

일 평균 200 기여도 기준 약 75일(2~3개월) 소요 — 문파 시스템을 장기 유지 콘텐츠로 배치.

**문파 특전 전체 테이블 (2026-07-27 신규 정의):** 이전엔 예시 2개(Lv10 +3%, Lv20 +2%)만 있어 [[스테이지-레벨링-기획서]] 7장 전투력 공식의 "문파 특전(%)" 항을 못 채웠다. 문파 레벨 상한을 50으로 두고 아래 누적 테이블을 정본으로 채택(개별 스탯 특전은 UX 플레이버로 유지, 전투력 계산용 종합치는 이 표 사용):

| 문파 레벨 | 누적 특전(%) |
|---:|---:|
| 10 | +3% |
| 20 | +7% |
| 30 | +12% |
| 40 | +18% |
| 50 | +25% |

`문파특전(%) = 위 표에서 현재 문파 레벨 이하 최고 구간값` — 문파 시스템(75일 소요)이 환골탈태(리셋 1회, 수십 분)의 즉각적인 +15%에 비해 투자 대비 낮아 보일 수 있으나, 문파 특전은 환골탈태로 초기화되지 않고 영구 유지되는 것이 차별점(장기 누적 가치).

## v1 구현 범위 (2026-09-10)

기존 "내공 기부" 경로에 이어 **"영약 기부"(영약 1개 = 기여도 10)** 경로를 추가 구현(SectPanel.tsx, store.ts `donateElixirToSect`). 기여도는 문파 레벨업(sectExp)에 소모되는 것과 별개로, 문파무공 강화용 소모 가능 잔액(`sectContributionPoints`)에도 동시에 누적된다 — 문파 레벨이 50에 도달해 더 이상 오르지 않아도 문파무공 투자는 계속 가능.

**문파무공 = 삼재검법 2보로 구현 (2026-09-10):** 청운문 전용 시그니처 초식명이 위키에 없어 보류를 고려했으나, 기획 단계에서 이미 "상위 보드(삼재검법 2보)는 하위 보드(삼재검법 1보)의 오의 노드(삼재합일)가 대성 상태여야 개방"이라고 예고해둔 지점과 정확히 일치한다고 판단해 여기 연결했다. 즉 청운문의 문파무공은 화산검법처럼 별도 계통이 아니라 삼재검법의 심화판(2보)이며, 강화 재화만 내공 대신 기여도를 쓴다(위키 "문파무공 해금 총량" 표의 BaseCost 20/100/800·growth 1.13·최대Lv 30/30/10 그대로, 노드명은 무공-시스템.md와 동일하게 신규 작명, 레벨당 효과%는 다른 보드와 동일 표 재사용). [[무공-시스템]] 참고. 문파원 목록·가입/이적·일일임무·주간토벌전은 멀티플레이 전제라 여전히 범위 밖이고, 타 문파 무공은 아래 "일대종사 · 타 문파 교류"로 얻는다.

## 일대종사 · 타 문파 교류 (2026-09-22)

청운문 레벨 50 이후의 목표이자 기여도 사용처. 목현은 청운문 소속을 유지한 채, 여러 문파에 은혜를 쌓아 무림 전체에 인정받는 **일대종사(一代宗師)** 가 된다. 타 문파 가입·이적 없이 그 문파의 무공을 전수받는 경로다.

- **문파 레벨 곡선:** 레벨당 필요 기여도 `30 × 1.06^(레벨−1)`, Lv50까지 누적 약 8,200 기여도(`sectData.ts`).
- **직책:** 청운문 Lv50 달성 시 "일대종사" 직책이 문파 화면에 표시되고 타 문파 교류가 열린다.
- **타 문파 레벨:** 문파 화면 "일대종사 · 타 문파 교류"에서 문파별로 [기여도 바치기]를 누르면 사용 가능 기여도를 그 문파 최대 레벨까지 필요한 만큼 바쳐 그 문파 레벨(Lv1~50)을 올린다. 곡선은 청운문과 같아 문파 하나를 Lv50까지 올리는 데 8,194 기여도가 든다. 바친 누적치(`sectFavor`)로 레벨을 계산한다(`sectData.ts` `otherSectLevel`).
- **레벨 특전:** Lv10마다 한 단계씩, 문파 성격에 맞는 보조 스탯이 오른다. Lv50 최대치는 화산파 공격속도 +3%, 무당파 회피율 +1.5%, 남궁세가 치명타 피해 +6%, 개방 내공 획득량 +5%, 소림사 치명타 확률 +2%(Lv10은 그 5분의 1). 무공 보조 스탯과 같은 축에 더해지고, 내 정보 "성장별 기여도"에 "타 문파" 행으로 보인다.
- **전수:** 그 문파가 Lv50이 되면 무공 보드가 열린다. 버튼이 [무공 보기]로 바뀌어 무공 탭 해당 보드로 이동한다.
- **보드:** 삼재검법 2보와 같은 트리·비용(기여도, BaseCost 20/100/800·growth 1.13·최대 Lv 30/30/10)이고 공통 가산 버킷에 더한다. 오의는 문파 성격에 맞는 보조 스탯이다([[무공-시스템]] "오의 보조 스탯").

| 문파 | 무공 보드 | 1차 노드 3개 | 2차 노드 2개 | 오의 (보조 스탯) |
|---|---|---|---|---|
| 화산파 | 매화검법(梅花劍法) | 매화점점(梅花點點) · 낙매표풍(落梅飄風) · 설중매(雪中梅) | 매화칠절(梅花七絶) · 이십사수매화(二十四手梅花) | 매화검강(梅花劍罡) — 공격속도 |
| 무당파 | 태극권(太極拳) | 운수(雲手) · 단편(單鞭) · 남작미(攬雀尾) | 태극음양(太極陰陽) · 사량발천근(四兩撥千斤) | 태극무극(太極無極) — 회피율 |
| 남궁세가 | 창룡검법 내편(蒼龍劍法 內篇) | 창룡탐조(蒼龍探爪) · 창룡파미(蒼龍擺尾) · 창룡음(蒼龍吟) | 검룡출수(劍龍出袖) · 제왕검세(帝王劍勢) | 창룡회천(蒼龍回天) — 치명타 피해 |
| 개방 | 항룡십팔장(降龍十八掌) | 항룡유회(亢龍有悔) · 비룡재천(飛龍在天) · 견룡재전(見龍在田) | 잠룡물용(潛龍勿用) · 신룡파미(神龍擺尾) | 항룡십팔(降龍十八) — 내공 획득량 |
| 소림사 | 백보신권(百步神拳) | 나한권(羅漢拳) · 금강권(金剛拳) · 반야권(般若拳) | 격공권(隔空拳) · 금강부동(金剛不動) | 백보일권(百步一拳) — 치명타 확률 |

- **장비 보상 (2026-09-23):** 그 문파에 처음 기여도를 바칠 때 1회 상징 슬롯 신품 1개, 5개 문파를 모두 Lv50(전수)으로 올리면 선품 신표 1개. 상세는 [[장구-시스템]] "신품·선품 획득 경로".
- **무공 탭 표시:** 기여도로 연마하는 보드(삼재검법 2보·타 문파 무공)는 "문파 무공" 탭에 모인다. 문파 무공을 하나라도 얻으면 무공 탭 상단에 [일반 무공 | 문파 무공] 탭이 생기고, 각 탭의 보드 목록은 해당 종류만 보여 준다.
- **기부 칸 숨김:** 청운문과 타 문파 5곳이 모두 Lv50이고 기여도로 연마하는 보드(삼재검법 2보·타 문파 무공 5개)가 전부 대성이면 기여도를 쓸 곳이 없어 문파 화면의 기부 칸을 숨긴다.
- **밸런스:** 레벨 곡선과 특전 수치는 구현 후 조정할 자리표시자다.
