# 무림인 키우기 — 개발 파이프라인 로드맵

현재 세로형·하단 4탭 UX를 바탕으로 신규 아트를 제작하고 게임에 연결하는 순서다. 구체적인 화면별 결과물과 검수 기준은 [[모바일-비주얼-디자인-제작-계획]], 자산별 수량은 [[모바일-디자인-에셋-제작-명세]]를 따른다.

## 0. 기준 화면과 디자인 토큰

무공 메인의 고정 전투 영역·독립 스크롤 무공 목록, 장비·문파·상점, 중앙 팝업을 현재 게임에서 캡처한다. 320/390/430px 화면의 가독성·겹침·에셋 빈자리를 기록하고 먹색·한지·금색·등급색의 역할, 타이포·간격·명암을 토큰으로 확정한다.

시안의 색상 값과 CSS 토큰은 출발점이다. 최종 인물·배경 원화와 나란히 놓고 패널, 버튼, 등급, 전투 HUD의 명도·색을 다시 맞춘다.

## 1. 신규 원화 기준 확정

목현·혈랑채 졸병·궁수·정예산적·두목 5종의 **새 대기 기준 이미지**를 만든다. 혈랑채 배경은 새 원화를 적용했다. 모두 약 2.5등신 SD 페인터리 그림체로 통일하고, 무공 메인의 640×390 전투 스트립에서 캐릭터·공격 범위·사냥터 버튼이 함께 보이도록 확인한다. HTML/SVG 시안은 구도와 UI 검토 자료이며 최종 캐릭터·배경 아트를 대신하지 않는다.

## 2. 대1 캐릭터·배경 신규 제작

승인한 새 외형을 기준으로 목현과 대1 적 4종의 현행 동작 구성 **27모션 시트·155프레임**을 새로 만든다. 기존 파일에서 프레임을 크롭·확대하는 작업으로 완료 처리하지 않는다. 생성 후보와 최종 투명 PNG·JSON을 구분하고, [[캐릭터-이미지-생성-지침]]의 방향, 공통 프레임·여백·기준점, 모션 간 신체 배율, 실제 알파를 검수한다.


## 3. UI 키트 제작과 게임 연결

현재 게임의 PixiJS 전투 캔버스 + React 화면에 새 대1 인물·배경을 연결한다. 하단 4탭, 재화·기능 아이콘, 전투 HUD, 무공 카드, 중앙 팝업의 공통 스타일을 먼저 무공 메인에 적용한 뒤 장비·문파·상점으로 확장한다. 각 화면에서 잠김·재화 부족·보스/보상·설정 상태를 확인한다.

## 적용 완료 조건

- 새 목현·대1 적 4종이 새 혈랑채 배경과 함께 게임 런타임에 연결되고 모바일 실제 크기에서 전 모션·안전 영역이 검수된다.
- 무공 메인, 장비·문파·상점, 중앙 팝업에서 아이콘·버튼·재화·잠금·등급의 뜻과 시각 품질이 일관된다.
- 320/390/430px에서 전투가 잘리지 않고 첫 무공 연마 행동, 단계 선택, 팝업 확인·취소를 읽고 누를 수 있다.
