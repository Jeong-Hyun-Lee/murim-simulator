# 모바일 비주얼 디자인 제작 계획

## 목적과 기준

무공 메인 상단의 고정 전투 영역, 그 아래 독립 스크롤 목록, 무공·장비·문파·상점 4탭과 중앙 팝업은 [[모바일-UX-개선-기획서]]의 현재 구조로 유지한다. 이 문서는 그 구조를 **실제 모바일 방치형 게임처럼 보이고 읽히게 만드는 시각 제작 순서**를 정한다. 화면 기능과 재화·해금 판정은 바꾸지 않는다. 제작 자산의 세부 수량과 캐릭터 납품 기준은 [[모바일-디자인-에셋-제작-명세]], [[캐릭터-이미지-생성-지침]]을 따른다.

2026-09-14 코드와 `assets/` 기준으로 혈랑채 신규 배경 1장, 목현과 대1 적 4종의 모션 시트, 타격 효과·숫자 이미지가 있다. 혈랑채 배경 원화는 런타임 WebP로 연결됐고, **목현과 대1 적 4종은 임시 스프라이트이므로 외형과 모션을 신규 제작해 교체한다.** 타격 효과·숫자는 모바일 실측 후 재사용 여부를 판단한다. 하단 탭·재화·무공·장비·문파·상점의 정식 아이콘과 화면 공통 장식 아트도 없다. 현재 `src/style.css`의 먹색·한지색·금색 토큰, 문자 중심 카드와 팝업은 동작 검증용 출발점이다. **시안의 문자 글리프나 CSS 도형을 완료된 아트로 세지 않는다.**

## 첨부 레퍼런스에서 가져올 원칙

|---|---|---|
| 이미지 1·2 | 캐릭터가 화면의 중심을 차지하고 장비·성장 정보를 가장자리 패널에 모음. 팝업은 배경을 어둡게 눌러 선택에 집중시킴 | 목현의 SD 전신을 장비와 전투의 주인공으로 유지. 장비 슬롯과 보상 팝업에 등급별 틀·명암을 주되 글자와 캐릭터를 가리지 않음 |
| 이미지 3·4 | 전투 풍경 위에 스테이지·체력 정보를 놓고 아래 공간에 성장 행동을 이어 붙임 | 지금의 무공 메인 구조를 시각적으로 연결. 전투 무대의 깊이와 상태 HUD를 강화하고, 무공 첫 연마 행동이 첫 화면에서 보이도록 높이 조정 |

첨부 화면의 특정 캐릭터·아이콘·테두리·레이아웃을 그대로 베끼지 않는다. 고전 판타지의 보석 장식과 픽셀 게임의 조밀함을 섞기보다, **2.5등신 SD 페인터리 캐릭터가 있는 무협 수련장**이라는 게임 자체의 방향으로 통일한다.

## 목표 시각 언어

- **장면:** 혈랑채 전투 무대는 먼 산·산채·바닥의 3층 깊이를 두고 캐릭터 실루엣과 공격 궤적이 먼저 읽히게 한다. 무공 화면 위에서는 풍경이 주인공이고, 아래 패널은 조작을 위한 기록장이다.
- **재질:** 먹색 옻칠, 어두운 목재, 낡은 한지, 절제한 청동·금박을 공통 재료로 쓴다. 배경·패널·선택 버튼이 같은 갈색 덩어리로 보이지 않게 명도와 질감을 분리한다. 청운문 청록과 전투 배경의 냉색을 보조색으로 두고 금색은 주요 행동에 집중한다.
- **위계:** ① 전투와 현재 스테이지, ② 바로 누를 성장 행동·비용, ③ 보유 재화·장비/문파 정보 순으로 읽힌다. 장식은 이 순서를 돕는 테두리·광택·문양에만 넣는다. 적 체력·버튼·문구를 배경 원화에 그려 넣지 않는다.
- **표현 규칙:** 숫자는 정렬 가능한 UI 글꼴, 장 제목과 장면명만 명조 계열을 검토한다. 아이콘은 선 굵기·시점·광원 방향을 통일하고 텍스트 이름을 병기한다. 등급 6색은 장비 품질, 금색은 주요 행동, 초록·빨강은 증감/체력으로 의미를 분리한다.
- **움직임:** 연마 가능·완료, 보스 대기, 보상 획득 정도만 짧게 강조한다. 전투 중 데미지 숫자와 UI 반짝임이 동시에 수치를 가리지 않게 하고 움직임 감소 설정에서도 문구로 결과를 확인한다.

## 단계별 작업과 승인 가능한 결과물

1. **기준 화면 수집:** 현재 게임의 320×568, 390×844, 430×932에서 무공 기본/보스 대기/일시정지, 장비, 문파, 상점, 사냥터·설정·보상 팝업을 캡처한다. 화면마다 자산 유무와 겹침·가독성 문제를 기록한다. 결과물은 화면 목록과 제작 우선순위표다.
2. **대1 원화 방향 확정:** 색·재질·타이포·아이콘 방향과 함께 새 목현·적 4종의 대기 기준 이미지, 새 혈랑채 무대 구도를 제작한다. 5종의 2.5등신 비율·표정·역할별 실루엣·광원·좌우 응시 방향을 나란히 확인한다. 기존 그림을 단순 보정하거나 확대하는 안은 최종안에 넣지 않는다.
3. **대1 아트 신규 제작·연결:** 승인한 기준 이미지로 [[캐릭터-이미지-생성-지침]]의 현행 동작 구성 27모션 시트/155프레임을 새로 만들고 실제 투명화·공통 셀·기준점·공격 범위를 검수한다. 적용된 혈랑채 배경 위에서 게임 런타임에 연결해 대기·공격·피격·사망·승리 전환을 확인한다. 기존 스프라이트는 새 에셋이 통과할 때까지 임시 표시용으로만 둔다.
4. **무공 메인·공통 키트 완성:** 새 캐릭터와 배경을 기준으로 **무공 메인 + 사냥터 팝업 + 하단 4탭**을 실제 게임 데이터와 함께 시각화하고 승인한 스타일을 재사용 가능한 상태별 컴포넌트·아이콘으로 옮긴다. 320×568에서는 상단 전투 영역을 현재 약 331px보다 낮춰 무공 목록에 최소 1개 연마 행동이 보이는 공간을 확보한다. 전투의 단계 선택·체력·캐릭터·효과를 숨겨 높이를 줄이지 않는다.
5. **나머지 탭·스토리 팝업 확장:** 장비 → 문파 → 상점 → 스토리 카드 순으로 시각 요소를 입힌다. 각 화면은 기본·잠김·재화 부족·실행 결과를 포함하고, 장비 비교/강화, 기부 확인, 기연 결과, 보스 보상, 환골탈태와 대1~30 스토리 자막·컷신에 공통 규칙을 적용한다. UX 구조와 실제 비용/해금 판정은 유지한다.
6. **기기 검수·정리:** 320/360/390/430px, 짧은 가로 화면과 글자 200%에서 오버플로·터치 영역·모달 스크롤·노치·새 전투 프레임 잘림을 확인한다. 주요 연마·장착·사냥터·설정 동작을 직접 조작하고, 저사양 기기에서 초기 로딩과 전투 프레임 저하를 확인해 에셋 출력 크기를 정한다.

## 완료 판정

- 첫 화면에서 **목현과 적, 현재 사냥터, 누를 수 있는 첫 무공 연마 행동**을 찾을 수 있다. 320px 폭에서 두 캐릭터와 공격 궤적이 잘리지 않는다.
- 4탭·재화·잠금·희귀도·전투 상태의 아이콘과 색이 모든 화면에서 같은 뜻을 갖는다. 숫자와 행동명은 장식 없이도 읽힌다.
- 사냥터·설정·보스/보상·비교 팝업은 배경과 구분되고, 중요한 선택·비용·취소가 한눈에 보이며 팝업 내용만 스크롤된다.
- 적용된 혈랑채 배경의 모바일 실측과 새 목현·대1 적 4종의 27모션 시트 런타임 연결이 모두 통과해야 대1 아트가 완료된다. 시안 이미지·기존 임시 자산·검증된 신규 런타임 에셋을 구분한다.
