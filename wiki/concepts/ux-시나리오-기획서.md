## 1. 화면 구성 개요

메인 화면(1920x1080)은 상단 고정바 + 좌/중/우 3분할 본체 + 하단 액션바, 총 4개 영역으로 나눈다. 모바일 방치형 게임의 "세로 스크롤 한 화면" 관례를 가로로 넓게 펼쳐, 좌측에는 원래 세로 게임에서 화면 전환으로 봤던 캐릭터 정보를, 우측에는 성장 트리 요약을 상시 노출시켜 탭 전환 없이도 핵심 루프(전투 확인 → 재화 확인 → 강화)가 한 화면에서 끊기지 않게 한다.

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│ [로고] 스테이지 | 무공 | 장구 | 문파 | 환골탈태 | 상점        내공 ●1.2만  영약 ◆320 │ 0,0 - 1920,70
├───────────────┬──────────────────────────────────────┬───────────────────────────┤
│  좌측 패널     │        중앙 캔버스 (대련뷰)            │      우측 패널             │
│ (0,70)~        │        (380,70)~(1540,930)            │   (1540,70)~(1920,930)    │
│ (380,930)      │                                        │                           │
│                │  ┌ 관문 진행바: 3-1 ▓▓▓░░░░░░░ 3-10 ┐ │  [추천 수련]              │
│ 캐릭터 초상화  │  │ (캔버스 상단 오버레이, y=70~110)   │ │  삼재검법 1보 · Lv12      │
│ 도호/경지      │  └────────────────────────────────────┘ │  "휘두르기" 다음 강화     │
│ 근골/오성/심법 │                                        │  [연마하기] 내공 1,200    │
│ 종합 전투력    │     캐릭터 vs 몬스터 자동 대련 애니메이션 │                           │
│ 착용 무공 요약 │                                        │  ─────────────            │
│                │                                        │  보유 무공 보드 목록      │
│                │                                        │  ▸ 삼재검법 1보 (진행중)  │
│                │                                        │  ▸ 태극권 (해금됨)        │
│                │                                        │  ▸ 매화검법 (🔒 6-1 필요)│
├───────────────┴──────────────────────────────────────┴───────────────────────────┤
│  [운기조식 자동전투 ON]  [일괄 연마]  [오프라인 보상 수령]   퀘스트 ▾   문파톡 ▾   │ 930,930 - 1920,1080
└──────────────────────────────────────────────────────────────────────────────────┘
```

- **상단 네비게이션 바 (0,0)–(1920,70)**: 좌측에 로고, 그 옆에 탭형 메뉴(스테이지/무공/장구/문파/환골탈태/상점). 우측 정렬로 재화 스트립 상시 노출(내공/영약/전 등). 탭은 클릭 시 중앙+우측 영역 컨텐츠만 교체하고 좌측 캐릭터 패널은 고정 유지.
- **좌측 캐릭터 패널 (0,70)–(380,930)**: 세로 방치형 게임의 "캐릭터 화면"을 상시 패널로 고정. 초상화, 도호(별명)와 경지(레벨/전투력), 근골·오성·심법 스탯, 현재 착용 중인 무공 요약 3줄.
- **중앙 캔버스 (380,70)–(1540,930)**: 실제 게임 렌더링 영역. 상단에 관문 진행바 오버레이, 그 아래로 캐릭터-몬스터 자동 대련 장면. 무공/장구 탭을 눌러도 이 캔버스는 계속 재생되며(백그라운드 전투 유지), 우측 패널만 해당 탭 컨텐츠로 바뀌는 것이 기본 동작.
- **우측 패널 (1540,70)–(1920,930)**: 컨텍스트 패널. 기본 상태에서는 "추천 수련" 카드(가장 효율 좋은 다음 강화 1개 하이라이트) + 보유 무공 보드 리스트(아코디언). 무공 탭 클릭 시 이 영역이 확장되거나, 트리가 넓어 화면이 부족하면 중앙을 덮는 대형 모달(1400x900 정도)로 보드 상세를 띄운다.
- **하단 액션바 (0,930)–(1920,1080)**: 자동전투 토글, 일괄 연마(모든 보드에 자동으로 재화 소비) 버튼, 오프라인 보상 수령(의미는 3-4절 참고 — 시간 비례 방치 성장이 아니라 고정형 재접속 보너스), 우측에 일일 퀘스트/문파 채팅 드롭업 위젯.

## 2. 성장보드(무공 트리) 화면 상세

### 2-1. 보드 진입 방법
- 상단 네비 "무공" 탭 클릭, 또는 우측 패널 "추천 수련" 카드 클릭, 또는 캔버스 내 캐릭터를 직접 클릭(빠른 진입 단축 동선) — 세 경로 모두 동일한 "무공 화면"으로 연결.
- 진입 시 좌측에 세로 탭 리스트(보유 무공 보드 전체: 삼재검법 1보, 삼재검법 2보, 태극권, 매화검법…), 우측 큰 영역에 선택된 보드의 노드 그래프가 펼쳐진다. 이 화면은 중앙 캔버스를 덮는 1400x900 모달(반투명 배경 딤 처리)로 열리되, 전투는 계속 백그라운드에서 진행(자동전투 중단 없음)됨을 상단에 작게 "대련 진행 중" 인디케이터로 표시.

### 2-2. "삼재검법 1보" 노드 구조
노드는 좌→우로 흐르는 트리형 그래프. 뿌리 노드에서 3갈래로 갈라졌다가 마지막에 합쳐지는 구조로, 검법의 "기본기 → 응용 → 오의"라는 무공 서사를 그대로 반영한다.

```
[기수식] ─┬─ [휘두르기] ─┬─ [반격]     ─┐
 (뿌리)   ├─ [찌르기]   ├─ [보법·경신술]├─ [삼재합일] (오의, 캡스톤)
          └─ [회피]     └─ (연계 보너스)┘
```

- **기수식(뿌리 노드)**: 보드 개방 즉시 Lv1로 자동 습득. 다른 모든 노드의 전제 조건.
- **휘두르기 / 찌르기 / 회피**: 1차 분기 노드. 각각 독립적으로 재화만 있으면 레벨업 가능(전제조건 없음). 각각 공격력%, 치명타%, 회피율% 등 서로 다른 스탯을 담당.
- **반격 / 보법·경신술**: 2차 분기 노드. 잠금 해제 조건은 "직속 상위 노드 Lv10 이상" 식으로 표기(예: 반격은 휘두르기 Lv10 필요). 해금 전에는 회색 처리 + 자물쇠 아이콘 + "휘두르기 Lv10 필요" 텍스트 오버레이.
- **삼재합일(캡스톤)**: 2차 노드 전부가 각 Lv30 이상이어야 해금. 해금 시 스탯 % 뿐 아니라 신규 필살기 연출(대련 화면에 특수 이펙트 추가) 부여.

### 2-3. 노드 카드 정보 구성
각 노드는 원형 아이콘 + 하단 정보 카드로 구성되며, 클릭 시 카드가 펼쳐져 다음 정보를 보여준다.

| 항목 | 표시 예시 |
|---|---|
| 초식명 | 휘두르기 |
| 현재 레벨 / 최대 레벨 | Lv 12 / 50 |
| 현재 효과 | 기본 공격력 +24% |
| 다음 레벨 효과(강화 후 미리보기) | Lv13 → 공격력 +25% (+1%p) |
| 강화 비용 | 내공 1,200 |
| 업그레이드 버튼 | [연마하기] — 노드 카드 우측 하단 고정 위치 |
| 버튼 상태 | 활성(재화충분, 금색) / 비활성(재화부족, 회색+부족량 빨간 텍스트) / MAX(초록, "대성(大成)") |

노드 카드 상단에는 "10연마"(비용 10배로 즉시 10레벨 강화) 보조 버튼도 함께 배치해, 방치형 관례인 "일괄 구매" 옵션을 제공한다.

**v1 구현 (2026-09-10):** "10배"를 다음 레벨 1회분 비용의 정액 배수가 아니라, 실제로 오르는 각 레벨의 개별 강화비용을 합산하는 방식으로 구현(`gongData.ts`의 `nodeBulkUpgrade`) — 위키의 "대성 총 내공" 표와 계산 기준을 통일하기 위함. 최대 레벨 근처에서는 남은 레벨만큼만 적용.

### 2-4. 보드 간 관계
- 좌측 세로 탭에서 보드 목록을 전환. 각 탭에는 보드 대표 아이콘 + 진행률 원형 게이지(예: 삼재검법 1보 62% 완성)가 함께 표시되어 어느 보드가 덜 채워졌는지 한눈에 파악 가능.
- 잠긴 보드(예: 매화검법)는 회색 탭 + 자물쇠 아이콘 + 해금 조건("6대 스테이지 클리어 필요" 또는 "화산파 가입 필요")을 툴팁으로 노출. 클릭은 되지만 내용 대신 해금 조건 안내 화면만 뜬다.
- 상위 보드(삼재검법 2보)는 하위 보드(삼재검법 1보)의 오의 노드(삼재합일)가 대성(MAX) 상태여야 개방 — "무공을 극성으로 익혀야 다음 단계로 넘어간다"는 무협 서사를 성장 트리 게이팅 조건으로 그대로 사용.
- 서로 다른 계통 보드(삼재검법 vs 태극권)는 개방 조건이 다르되(스테이지 진행 vs 문파 가입), 화면 구조/노드 카드 UI는 완전히 동일한 템플릿을 재사용해 학습 비용을 낮춘다.

## 3. 스테이지 진행 화면

### 3-1. 관문 진행바
중앙 캔버스 상단(y=70~110 부근)에 고정 오버레이로 표시. 현재 대스테이지 이름("제3장: 종남산")과 함께 소스테이지 10칸을 점/세그먼트 바로 표현한다.

```
제3장: 종남산      3-1 ● ● ● ▓ ○ ○ ○ ○ ○ [☠3-10]
                        ↑현재(3-4)              ↑보스 강조(붉은 해골 아이콘, 칸이 더 큼)
```

- 클리어한 칸은 채움(●), 현재 도전 중인 칸은 펄스 애니메이션(▓), 미도달 칸은 빈 원(○).
- 10번째 칸(보스전)은 다른 칸보다 아이콘이 크고 붉은 테두리로 강조, 상시 "보스" 라벨 부착.
- 대스테이지 클리어 후에는 진행바 전체가 좌→우로 슬라이드 아웃 되며 다음 장 이름으로 교체되는 트랜지션.

### 3-2. 자동전투
- 기본값 ON. 하단 액션바의 "운기조식" 토글 버튼으로 on/off (무협 용어로 "자동으로 내공을 돌린다"는 의미를 살림). OFF 시에도 캐릭터는 정지하지 않고 수동 조작 없이 관전만 가능(이 게임은 조작 개입 요소가 없는 순수 방치형이므로 OFF는 사실상 "일시정지" 의미에 가깝게 처리).
- 진행 속도 배속 버튼(x1/x2/x4)을 진행바 우측 끝에 작게 배치.

### 3-3. 전투 결과 / 보상 팝업
- 소스테이지 클리어: 캔버스 우상단에서 슬라이드 인 되는 작은 토스트 팝업(1.5초 노출 후 자동 소멸) — 획득 내공량, 드롭 아이템 아이콘 나열. 자동전투 중이므로 다음 스테이지로 즉시 자동 진행, 팝업이 진행을 막지 않음.
- 대스테이지 보스 조우 직전: 진행을 멈추고 중앙에 보스 예고 다이얼로그 출현(보스 초상화, 이름 — 정식 보스명은 [[스테이지-레벨링-기획서]] 1.3절 매핑표 기준, 체력/추천 전투력 대비 내 전투력 비교 바) + [도전] 버튼. 자동전투 ON이어도 보스전은 1회 확인을 받도록(방치형 관례상 과금/장비 점검 유도 지점) 예외 처리.
- 보스전 중: 캔버스 상단에 보스 전용 붉은 체력바 추가 표시(플레이어 체력바 아래).
- 보스 격파: 화면 전체 암전 후 금빛 파티클과 함께 중앙 대형 보상 팝업 — 보상 재화/장비 + "신규 무공 보드 해금!" 배너(해당되는 경우) + [계속하기] 버튼. 이 팝업은 자동전환 안 하고 사용자 확인 필요(성취감 강조 지점).

**v1 구현 범위 (2026-09-10):** 보스 초상화/체력·전투력 비교 바, 화면 암전+금빛 파티클, 보드 해금 배너는 캔버스 연출 인프라가 없어 범위 밖 — 보스명 텍스트 + [도전]/[계속하기] 버튼만 있는 단순 확인 다이얼로그(`BossDialog.tsx`)로 축소 구현. 확인 전까지 자동전투(공격 틱)가 멈추는 핵심 동작은 그대로 구현됨.

### 3-4. 오프라인 보상 버튼의 정확한 의미 (2026-07-27 정리)

프로젝트 원칙("오프라인 방치 성장은 우선 고려하지 않는다")과 하단 액션바의 "오프라인 보상 수령" 버튼이 서로 모순돼 보인다는 지적이 있었다. 아래로 명확히 한다:

- 이 버튼은 **경과 시간에 비례하는 방치 성장 계산이 아니다.** 오프라인 동안 스테이지가 실제로 진행되거나 재화가 시간당 누적되지 않는다(원칙 그대로 유지).
- 대신 **"재접속 환영 보너스"** — 1일 1회, 마지막 접속 이후 재접속 시 고정 수량(내공 소량 + 영약 1~2개)을 지급하는 로그인 보상에 가깝다. 접속 시간에 무관하게 정액이며, "오프라인 보상"이라는 이름은 방치형 게임 관례를 따른 라벨일 뿐 실제로는 일일 접속 보상이다.
- 버튼은 최초 미수령 상태에서만 골드 테두리로 강조(추천 상태 컨벤션 재사용), 수령 후 비활성 처리되고 다음 날 자정 리셋.

## 4. 핵심 사용자 플로우

1. **전이 인트로 컷씬**: 화면 전체 풀스크린 연출. 현대인 주인공이 사고/각성 → 정신을 잃고 무림 세계 절벽/객잔 앞에 쓰러짐, 3~4장의 정지 일러스트 + 하단 대사창(자동 넘김 또는 클릭으로 다음 대사). 우상단에 상시 "SKIP" 버튼 노출 — 언제든 즉시 스테이지 화면으로 점프 가능.
2. **캐릭터 설정**: 도호(별명) 입력 또는 추천 이름 중 선택하는 짧은 팝업(선택 스킵 가능, 미입력시 기본값 자동 배정).
3. **튜토리얼 진입**: 화면 나머지는 딤 처리하고 중앙 캔버스의 [수련 시작] 버튼만 밝게 강조 + 화살표 애니메이션으로 클릭 유도. 클릭 시 1-1 스테이지 자동전투 시작.
4. **첫 스테이지 클리어**: 1-1은 즉시 클리어되도록 난이도 설계, 보상 팝업과 함께 "내공을 얻었다!" 툴팁이 상단 재화 스트립을 가리키며 등장.
5. **첫 성장보드 강제 개방**: 튜토리얼이 하단 액션바 "무공" 관련 진입 지점(우측 패널 추천 수련 카드)을 화살표로 지목 → 클릭 유도 → 삼재검법 1보 모달 오픈, "휘두르기" 노드만 밝게 강조되고 나머지는 딤 처리 → [연마하기] 버튼 1회 클릭 강제 → 클릭 즉시 스탯 상승 수치가 팝업(+24% 공격력!)으로 표시되고 캐릭터 좌측 패널 전투력 수치가 카운트업 애니메이션.
6. **튜토리얼 종료 & 자유 진행 전환**: 모달 닫힘, 캔버스 복귀, 강화된 캐릭터가 이전보다 빠르게 몬스터를 처치하는 것을 잠깐 관찰시킨 뒤, 하단 좌측에 일일 과제 체크리스트 위젯이 슬라이드 인 되며 "다음 목표: 3-1 스테이지 클리어" 등 자연스러운 후속 유도 제공. 이후 전체 UI 조작 자유화.

## 5. 공통 UI 컨벤션

### 5-1. 재화 표시
- 상단 바 우측에 아이콘+숫자 스트립으로 상시 노출: 내공(파란 물방울 아이콘, 기본 성장 재화), 영약(보라 호리병 아이콘, 프리미엄 재화), 전/은자(금화 아이콘, 장구 구매용 소프트 재화), 오성구슬(보라 구슬 아이콘, 초식 진화 전용 특수 재화).
- 큰 숫자는 한국형 단위(만/억/조)로 축약 표기: 12,000 → 1.2만, 340,000,000 → 3.4억. 재화 아이콘 클릭 시 획득처 안내 툴팁(어디서 얻는지) 노출.

### 5-2. 버튼 상태
| 상태 | 스타일 |
|---|---|
| 활성(강화 가능) | 금색/청색 배경, 텍스트 선명 |
| 추천/강조 | 은은한 골드 테두리 발광 + 우상단 느낌표 배지 |

| 최대 달성 | 초록 배경 + "대성(大成)" 라벨, 더 이상 클릭 불가 |

## 6. 온보딩 노출 순서 (2026-07-27 신규 정의)

4장 핵심 플로우는 "무공" 탭 강제 개방(대1 진입 직후)까지만 다뤘다. 나머지 4개 탭(장구/문파/상점/환골탈태)은 아래 순서로 스테이지 진행에 맞춰 순차 노출한다 — 전부 처음부터 열려있으면 신규 유저가 과부하를 느끼므로, 상단 네비 탭 자체를 조건 충족 전까지는 "곧 열림" 잠금 아이콘으로 숨겨둔다(무공/스테이지 탭만 최초부터 완전 노출).

| 순서 | 탭 | 최초 노출 시점 | 노출 방식 |
|---|---|---|---|
| 1 | 스테이지 | 게임 시작(1-1) | 항상 노출 |
| 2 | 무공 | 대1 진입 직후 | 4장 5단계에서 강제 튜토리얼로 개방 |
| 3 | 장구 | 대1-5 클리어(첫 장구 드롭 발생 시점) | 첫 장구 획득 토스트에 "장구 탭이 열렸습니다" 배너 병기, 상단 네비 탭에 NEW 배지 |
| 4 | 문파 | 대2 클리어 | 상단 네비 탭 NEW 배지, 별도 팝업으로 "청운문 문파 화면이 열렸습니다" 1회 안내 — **신규 가입이 아니라 이미 소속된 청운문의 문파 UI가 처음 열리는 것**(2026-07-27 수정, [[스토리보드-기획서]]상 목현은 1장부터 청운문 제자). [[문파-시스템]] 목록 화면에서도 청운문은 다른 문파처럼 "가입 신청" 카드가 아니라 처음부터 "내 문파" 카드로 표시된다. |
| 5 | 상점(일반) | 대1-10 보스 클리어(첫 재화 여유 시점) | NEW 배지만, 별도 팝업 없음 |
| 6 | 기연(가챠, 상점 하위탭) | 영약 100 최초 보유 시점 | 상점 진입 시 기연 서브탭에 NEW 배지 |
| 7 | 환골탈태 | 탭 자체는 대1부터 보이되 잠김(자물쇠+"대7 보스 클리어 필요") | 대7 클리어 즉시 잠금 해제 애니메이션 + 1회 안내 팝업(연출 순서는 아래 6-1절 참고) |

### 6-1. 대7(심마) 클리어 시 연출 순서 (2026-07-27 추가)

대7 보스는 일반 몬스터가 아니라 [[스테이지-레벨링-기획서]] 1.3절의 "심마 내면전" 특수 연출이며, 동시에 스토리 클라이맥스(소주천 완성)·환골탈태 탭 해금·태을혼원공 신규 보드 해금이 전부 겹치는 유일한 지점이다. 아래 순서로 하나씩만 재생해 겹치지 않게 한다:

1. 심마 격파 특수 컷씬 전체 재생(일반 보스 격파 팝업 대신 전용 연출, SKIP 불가 — 서사적 비중이 크므로).
2. 컷씬 종료 후 통상 보스 보상 팝업(재화/장비) 노출, [계속하기].
3. 환골탈태 탭 잠금 해제 애니메이션 + 1회 안내 팝업.
4. 마지막으로 "태을혼원공 신규 보드 해금!" 배너.

넷 다 순차적으로 하나씩, 사용자 확인([계속하기]/닫기) 후에만 다음 단계로 넘어간다 — 여러 팝업이 동시에 겹쳐 뜨지 않는다.

## 7. 메타 UI (최소 설계, 2026-07-27 신규 정의)

기존 문서에 전혀 없던 시스템/계정 관련 화면을 최소 범위로 정의한다.

- **설정**: 상단 네비 우측(재화 스트립 옆) 톱니바퀴 아이콘 → 팝업. 항목: 사운드 on/off(BGM/효과음 개별), 언어, 로그아웃/계정 전환. 별도 대형 화면 아님, 작은 팝업으로 충분.
- **공지/점검 배너**: 상단 네비 바로 아래 얇은 배너(닫기 가능, 세션당 1회만 자동 노출). 점검 예정 시 카운트다운 텍스트 포함.
- **우편함(보상함)**: 하단 액션바에 봉투 아이콘 추가, 미수령 개수 배지. 문파 하사품/이벤트 보상/보상 지급 실패 재지급 등을 여기서 수령. 클릭 시 리스트 팝업(각 항목 [수령]/[전체 수령] 버튼) — 인벤토리 리스트와 동일한 리스트 UI 템플릿 재사용.
- **랭킹**: 문파 탭 내부에 "명부(名簿)" 서브탭으로 배치(서버 전체 전투력 랭킹 Top 100 + 내 순위 고정 표시줄). 별도 상단 탭을 새로 만들지 않고 문파 시스템에 얹어 탭 개수 증가를 막는다. **주의(2026-07-27 추가):** 이 기능은 서버 측 실시간 집계(백엔드)를 전제한다 — 지금까지 위키 어디에도 서버/백엔드 아키텍처가 정의된 적 없으므로, 랭킹은 백엔드 설계가 시작되기 전까지는 "문파 내부 기여랭킹"(이미 정의됨, 서버 집계 불필요한 소규모 범위)으로 축소 운영하고 서버 전체 랭킹은 백엔드 착수 이후로 미루는 것을 권장한다.
- **로딩 화면**: 게임 최초 진입 시 브랜딩 로고 + 진행률 바(퍼센트 텍스트), 로딩 완료 후 바로 4장 1단계(전이 인트로 컷씬)로 연결.

범위 밖으로 명시: 실결제 수단 선택 UI, 소셜 공유 기능, 전투 로그 패널, 반응형/모바일 대응은 이번 정리에서 다루지 않는다(별도 브레인스토밍 항목으로 남겨둠, [[기획-공백-브레인스토밍]] 참고).
