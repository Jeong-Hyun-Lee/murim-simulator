외부 이미지 생성 AI(Midjourney/Stable Diffusion류)에 그대로 복사 붙여넣기할 텍스트 프롬프트 큐. 이 문서 자체는 이미지를 생성하지 않는다 — 사용자가 아래 프롬프트를 외부 AI에 입력해 이미지를 받아온 뒤, 캐릭터는 프레임 좌표만 크롭·리사이즈해 페인터리 그대로 스프라이트화(2026-09-11부터 — 이전엔 Aseprite 도트 트레이싱 방식이었으나 폐기, [[개발-파이프라인-로드맵]] 2단계 참고), 배경/UI는 그대로 또는 재가공해 `raw/assets/`나 `assets/`에 반영하는 흐름을 전제로 한다.

각 항목은 [[에셋-아트-컨셉]]/[[배경-아트-컨셉]]/[[비주얼-디자인-시스템]]에 텍스트로만 정의돼 있고 아직 실제 이미지가 없는 대상 중, 게임 진행상 노출 빈도가 높은 순으로 선정한다. **회차 상한 20개**(카테고리 합산, 2026-09-11 기존 5개에서 상향), 이미 이 문서에 등재된 대상은 이후 회차에서 전부 제외한다.

**프롬프트 작성 공통 규칙 (모든 카테고리 적용, 2026-09-11):** 프롬프트는 그럴듯한 그림 한 장이 아니라 실제 이 게임 화면에 바로 꽂아 넣을 소재여야 한다 — 항목마다 아래 기준으로 "현재 프로젝트에 실제로 적용 가능한 형태"인지 확인하고 프레이밍/시점을 프롬프트에 명시한다.

- **배경**: 전투 캔버스는 960×540(16:9) 고정 화면의 횡스크롤형 2D 사이드뷰다. 반드시 가로로 넓은 사이드뷰(side-view/side-scroller perspective) 시점으로 요청하고 탑다운·아이소메트릭·정면 초상 구도는 금지한다. 전경-중경-원경 3단 레이어 구도로 깊이감을 준다(기존 흑시장 프롬프트가 이 기준의 정본 예시).
- **캐릭터**: 전투 캔버스에서 플레이어(목현)는 화면 왼쪽에 서서 오른쪽(적)을 바라보고, 적 캐릭터는 화면 오른쪽에 서서 왼쪽(플레이어)을 바라본다 — 적 캐릭터 프롬프트는 반드시 "character facing left / facing screen-left (opposite of the player-character reference, which faces right)"를 명시. 스타일은 페인터리로 요청(도트/픽셀아트 요청 금지 — 2026-09-11 도트 컨셉 전면 폐기, [[에셋-아트-컨셉]] §3·§4 참고), idle/attack/death 각 6프레임 시트로 요청해 프레임 좌표만 크롭·리사이즈하면 바로 스프라이트화되게 한다(**death 시트 2026-09-11 추가** — 보스 격파·잡몹 처치 연출에 죽음/쓰러지는 모션이 필요해 idle/attack 2종만으로는 부족함을 확인, 마지막 프레임은 완전히 쓰러진 정지 자세로 홀드시켜 애니메이션 끝에서 정지 프레임처럼 활용 가능하게 한다). **각 프레임/패널에 번호나 라벨을 표시하지 않도록 negative prompt에 명시**(2026-09-11 추가 — 프레임 좌표만으로 크롭하는 방식이라 패널에 번호가 찍히면 오히려 지우고 마스킹해야 하는 불필요한 후처리가 생긴다).
- **UI/이펙트**: 다크 무협 HUD(근흑 배경, 금/주황 포인트) 위에 합성될 것을 전제로 하되, 배경 자체는 요청하지 않는다 — 배경 없음/투명(2026-09-11부터, 이전엔 근흑 `#100d0a` 단색 배경을 요청했으나 아래 공통 규칙에 따라 폐기).
- **배경이 아닌 모든 이미지(캐릭터/폰트/이펙트 등) 공통 (2026-09-11 추가):** '배경' 카테고리를 제외한 모든 이미지는 배경 자체가 없는(투명/제거된) 상태로 생성 요청한다 — 각 패널/프레임에 단색 배경을 채워 넣고 나중에 크롭·제거하는 방식 대신, 프롬프트 단계에서 처음부터 "no background, transparent background, isolated subject only"를 명시해 배경 제거 후처리 자체가 필요 없게 한다. 대기 중인 프롬프트 8건(캐릭터 5, UI·이펙트 3)에 전부 소급 반영 완료. 배경(background) 카테고리는 배경 자체가 생성 대상이므로 이 규칙에서 제외.

**완료 시 처리:** 이미지를 실제로 확보하면 해당 항목을 "완료" 절로 옮기고 **프롬프트 본문(코드 블록)은 삭제**한다 — 확보 경로(파일명)와 간단한 스펙 참고 링크만 남긴다. 나중에 재생성이 필요해지면 그때 다시 작성한다.

**임시(placeholder) 에셋은 완료가 아니다 (2026-09-11):** 클로드가 직접 만든 자체 제작 임시 에셋(SVG 래스터화, 프로시저럴 도형 등 — 외부 이미지 생성 AI 산출물이 아닌 것)은 실제로 게임 코드에 적용돼 `assets/`에 파일이 존재하더라도 "이미지 완성"으로 치지 않는다. "대상 선정" 단계에서 파일 존재 여부만으로 완성 판정하지 말 것 — 이 문서에서 **"완료"**로 옮겨졌는지만으로 판단한다. 임시 에셋이 적용된 항목은 계속 **"대기 중"**에 남기고 실제 프롬프트를 그대로 유지하며, 항목 설명에 임시 에셋의 실제 경로를 적어 "지금은 이걸로 임시 대체 중"임을 표시한다.
