**Goal:** 슬롯 시트 "현재 장비" 섹션에 장착 중인 장비의 실제 능력치를 표시한다.

**Architecture:** `GearPanel.tsx` 안에 `StatList` 프레젠테이셔널 컴포넌트를 추가하고, 기존 `SlotSheet`의 "현재 장비" 섹션에서 렌더링한다. 새 상태·훅 없음 — `itemBaseStats()` 순수 함수 결과를 그대로 나열.

**Tech Stack:** React + TypeScript (기존 GearPanel.tsx 패턴 그대로 사용, 신규 의존성 없음).

## Global Constraints

- 설계 문서: `docs/superpowers/specs/2026-09-14-장비-능력치-표시-design.md`

### Task 1: StatList 컴포넌트 추가 및 SlotSheet 연결

**Files:**
- Modify: `src/components/panels/GearPanel.tsx`

**Interfaces:**
- Consumes: `itemBaseStats(item: GearItem): Partial<Record<StatKey, number>>` (기존, `src/game/store.ts`를 통해 이미 import됨, `GearPanel.tsx:12`), `STAT_LABEL: Record<StatKey, string>` (기존, `GearPanel.tsx:24-34`), `GearItem` 타입 (기존 import, `GearPanel.tsx:18`).
- Produces: `StatList` 컴포넌트 — `({ item }: { item: GearItem }) => JSX.Element`. 이후 다른 태스크 없음(단일 태스크 플랜).

- [x] **Step 1: `StatList` 컴포넌트 정의 추가**

`GearPanel.tsx`의 `StatDiff` 컴포넌트(현재 44-69번 줄) 바로 다음, `EnhanceBlock` 컴포넌트(현재 71번 줄) 바로 앞에 삽입:

```tsx
const StatList = ({ item }: { item: GearItem }) => {
  const stats = itemBaseStats(item);
  const keys = Object.keys(stats) as StatKey[];
  return (
    <dl className="stat-list">
      {keys.map((key) => (
        <div className="stat-row" key={key}>
          <dt>{STAT_LABEL[key]}</dt>
          <dd>{(stats[key] ?? 0).toFixed(1)}</dd>
        </div>
      ))}
    </dl>
  );
};
```

- [x] **Step 2: `SlotSheet`의 "현재 장비" 섹션에서 렌더링**

`GearPanel.tsx`의 `SlotSheet` 컴포넌트 안, 현재 아래 코드(약 174-187번 줄):

```tsx
        {equipped ? (
          <>
            <div className="item-line">
```

