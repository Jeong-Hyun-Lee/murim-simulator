# 목현 v3 전투 스프라이트 설계

## 목표

목현의 기존 런타임 시트는 유지한 채, 새 외형 기준으로 `idle`·`attack1`·`attack2`·`death` 전 모션을 제작해 단일 PixiJS v8 스프라이트시트 PNG와 JSON으로 납품한다.

## 고정 규격

- 그림체: 2.5등신 SD 페인터리 무협, 청록·아이보리 무복, 흑발 상투와 청록 끈, 은색 직검.
- 방향: 전투 화면 왼쪽에서 오른쪽 응시.
- 모션: idle 12프레임(960ms), attack1 16프레임(720ms), attack2 16프레임(720ms), death 14프레임(1080ms·마지막 360ms 홀드).
- 공통 셀: 768×768px, 주인공 anchor `(0.25, 0.8125)`, 기준점 `(192, 624)`, 표시 배율 0.5.
- 최대 크기: 한 모션별로 다르게 확대하지 않는다. 가장 넓은 공격 포즈를 포함하는 공통 최대 신체 크기를 먼저 측정해 모든 프레임에 같은 배율을 적용한다.
- 납품: 후보 원화, 16열×4행 정렬 시트, 4096px 이하 단일 PNG, PixiJS hash JSON, 정상·저속 GIF, 검수 기록.

## 제작 흐름

1. 대기 원화를 외형 기준으로 확정하고, 공격1·공격2·사망의 최대 점유 키포즈를 만든다.
2. 각 모션의 준비·가속·타격·후속·복귀 또는 경직·낙하·착지 구간을 실제 관절·무기·옷자락 변화가 있는 개별 프레임으로 채운다.
3. 모든 프레임을 공통 기준점과 공통 최대 배율로 정렬한다. 생성 원본의 셀 크기가 달라도 내용별 자동 확대는 하지 않는다.
4. 알파·안전 여백·방향·프레임 고유성·정상/저속 GIF를 검수한다.
5. 트림 패킹과 PixiJS JSON 생성 후, 애니메이션 수·duration·anchor·복원 좌표를 검사한다.

## 완료 기준

- 네 모션이 정해진 프레임 수와 전체 재생 시간을 만족한다.
- 주인공의 외형·방향·발 기준선·최대 배율이 모든 프레임에서 일관된다.
- 시작/종료 접속 프레임을 제외한 인접 프레임은 최소 두 동작 요소가 구분된다.
- 실제 알파, 단일 시트·JSON, GIF와 게임 로더 검수를 통과한다.
