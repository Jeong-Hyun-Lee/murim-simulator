# 강화 꾹 누르기 연속 강화 · 분해 시 강화 골드 환급

## 배경

사용자 요청 3건 중 밸런스 조정(무공 해금 대비 레벨 격차)은 시뮬레이터 조사 결과 예상보다 복잡한 문제(환골탈태 시 무공 레벨 전체 리셋이 주원인으로 추정)로 확인돼 별도 논의로 보류. 이 문서는 나머지 두 건만 다룬다.

1. 장비 강화 버튼을 꾹 누르고 있으면 연속으로 강화되도록.
2. 강화된 장비를 분해할 때, 강화에 투자한 골드 일부를 환급하도록.

## 1. 강화 연속 입력

`src/hooks/useHoldRepeat.ts`가 이미 존재 — `GongPanel.tsx`의 "1회 연마" 버튼이 사용 중인 훅을 그대로 재사용한다. 짧게 누르면 1회 클릭, 400ms 이상 누르고 있으면 60ms 간격으로 반복 실행되고, 손을 떼거나 `disabled`가 true가 되면(재화/강화석 소진, 보호부적 부족, 최대 강화 도달) 자동으로 멈춘다.

`GearPanel.tsx`의 `EnhanceBlock` 컴포넌트에서 `+N 강화하기` 버튼에 `useHoldRepeat(enhance, disabled)`를 연결한다. 기존 `enhance` 함수(강화 실행 + 효과음 + 결과 텍스트 갱신)를 그대로 액션으로 넘긴다 — 반복 중에도 매 틱마다 성공/실패 효과음과 결과 문구가 갱신되는 것을 그대로 허용한다(연마 화면과 동일한 패턴, 별도 스로틀링 없음).

## 2. 분해 시 강화 골드 환급

### 현재 동작

`disassembleStoneYield(items)` (`store.ts`)가 등급만 보고 강화석 개수를 정한다 — 강화 단계는 반영하지 않는다. `GearItem`은 `enhanceLevel`만 저장하고 시도 이력(성공/실패 횟수, 실제 소모한 골드 총액)은 저장하지 않으므로, 정확한 "투자한 골드 총액"은 계산할 수 없다.

### 설계

근사치로 "성공만 가정한 누적 강화 비용"을 기준 삼는다:

```
enhanceGoldRefund(item) = round(Σ_{i=0}^{enhanceLevel-1} enhanceCost(i) × 0.5)
```

`enhanceCost`는 `gearData.ts`에 이미 있는 함수(단계별 강화 시도 비용)를 그대로 재사용. 여러 아이템을 한 번에 분해할 때는 각 아이템의 환급액을 합산.

- 기존 강화석 환급(`disassembleStoneYield`, 등급 기준)은 그대로 유지 — 이번 변경은 골드 환급을 추가하는 것이지 강화석 로직을 바꾸는 게 아니다.
- `GearPanel.tsx`의 분해 확인 시트("장비 분해")에 강화석 개수와 함께 "전 N 환급" 문구를 추가.
- `disassembleItems` 스토어 액션이 `gold`에 환급액을 더하도록 수정.

## 검증

- `npm run lint` 통과.
- 브라우저: 강화한 장비(+5 이상)를 분해해 강화석과 함께 골드가 늘어나는지, +0 장비는 골드 환급이 0인지 확인.
- 강화 버튼을 마우스로 꾹 눌러 여러 단계 연속 강화되는지, 최대 강화(+15) 도달 시 자동으로 멈추는지 확인.
