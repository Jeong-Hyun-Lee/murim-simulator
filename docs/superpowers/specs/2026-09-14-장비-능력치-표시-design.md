# 장비 능력치 표시

## 배경

`GearPanel.tsx` 슬롯 시트의 "현재 장비" 섹션은 등급/강화 단계만 보여주고, 실제 능력치(공격/방어/체력 등)는 소지품 후보와 비교할 때(`StatDiff`)만 노출된다. 장착 중인 장비 자체의 능력치를 바로 확인할 방법이 없다.

## 범위

- 슬롯 시트 "현재 장비" 섹션에만 적용.
- 소지품 후보 카드, 인벤토리 그리드 카드는 이번 범위 밖.

## 설계

`SlotSheet`의 "현재 장비" 섹션에 `StatList` 컴포넌트를 추가한다.

- 위치: `GradeChip` 아래, `EnhanceBlock` 위.
- 데이터: `itemBaseStats(equipped)` (기존 `StatDiff`가 쓰는 동일 함수) → `StatKey`별 값.
- 표시: `STAT_LABEL`로 라벨 매핑, `<dl className="stat-list">` + `<div className="stat-row">` 구조 (기존 `EnhanceBlock`과 동일 CSS 클래스 재사용, 신규 스타일 불필요).
- 값 포맷: `toFixed(1)`, 단위 접미사 없음 (기존 `StatDiff`와 동일 컨벤션 유지).
- 강화 버프%(`enhanceBuffPercent`)는 이번 범위에서 제외 — 슬롯별 집계가 아닌 전역 가산 버킷이라 개별 아이템 표시와 맞지 않음.

## 검증

- `npm run lint` 통과.
- 브라우저에서 장비 장착 후 슬롯 시트 열어 능력치 목록이 실제 값(0 아님)으로 뜨는지 확인.
